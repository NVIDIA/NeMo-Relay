Construct a foreign stream source. Relay owns the state when the call starts, even if it fails. The free callback runs exactly once after reads and close finish. Reads run on blocking workers. They restore the Relay middleware context so callbacks can emit observability events. Close callbacks restore the source creation scope and active trace context. Callbacks can use supplied capabilities and emit observability events. Other API calls, including managed-stream control and flushes, are invalid.

## Safety

Callbacks and state must stay valid and thread-safe until free. Cancel must promptly unblock reads. Close runs once after reads finish. Output strings transfer ownership and must follow `nemo_relay_string_free`'s allocator contract.
