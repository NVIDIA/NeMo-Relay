Copy opaque callback failure IDs into the current last error. Call after `nemo_relay_set_last_error_message` on the same thread. Relay carries every selected ID without changing the error text. A count of zero clears the IDs. The binding owns the data behind each ID.

## Safety

`ids` must point to `count` readable `uint64_t` values for this call. It may be null when `count` is zero. IDs must be nonzero.
