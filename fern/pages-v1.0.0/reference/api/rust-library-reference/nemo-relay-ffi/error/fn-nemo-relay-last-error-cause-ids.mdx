Read the opaque callback failure IDs associated with the last error. Writes the number of IDs to `out_count`. An empty list returns null. Read on the same thread as `nemo_relay_last_error`. The returned array is borrowed until the error message or cause IDs change. Do not free it.

## Safety

`out_count` must point to writable storage for one `uintptr_t`.
