Integer-backed numeric representation selected from a typed metric measurement's value fields.

This is intentionally not a Rust enum because foreign callers can supply any `int32_t` value. Exported functions validate the value before converting it to the core metric value type. Zero is reserved as unspecified so a zero-initialized measurement cannot select a value field accidentally.
