Per-call context delivered to a tool execution intercept.

The context carries the tool name, the argument payload entering this intercept, and the provider-issued tool-call correlation identifier recorded on the managed tool handle. Intercepts that complete execution without invoking the remaining chain use `tool_call_id` to associate their result with the originating tool call.
