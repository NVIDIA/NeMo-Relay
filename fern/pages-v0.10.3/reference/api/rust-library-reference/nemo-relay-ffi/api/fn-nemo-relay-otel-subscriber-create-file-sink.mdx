Creates one typed OpenTelemetry exporter subscriber that writes OTLP to a file.

`otel_type` must be `full`, `gen_ai`, or `openinference`. `output_directory` is required. `filename` may be null to use a default name for the format. `format` is `json_lines` (the OpenTelemetry file-exporter specification's serialization, and the default when null) or `proto`. `mode` is `overwrite` (the default when null) or `append`.

The projection controls match the endpoint entrypoints: `mark_projection` is `inherit`, `event`, or `tool`; `mark_exclude_names_json`, `promote_metadata_prefixes_json`, and `promote_resource_metadata_prefixes_json` are JSON arrays of strings; `attribute_mappings_json` is a JSON array of `{"key","alias"}` objects; and `completed_span_context_ttl_millis` must be greater than zero. A null JSON pointer takes the core default.

## Safety

Any non-null C strings must be valid and `out` must be non-null.
