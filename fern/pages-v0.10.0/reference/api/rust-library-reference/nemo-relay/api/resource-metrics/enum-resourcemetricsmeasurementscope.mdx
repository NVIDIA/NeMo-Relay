Measurement boundary selected for resource metric collection.

## Variants

### `RuntimeDefault`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "RuntimeDefault"}} /></pre>

Choose the default for the runtime: global in the CLI, or the current process tree in APIs.

### `Global`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Global"}} /></pre>

Collect resources for the full system visible to the running environment.

### `ApplicationProcess`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "ApplicationProcess"}} /></pre>

Collect resources for the process containing the Relay runtime.

### `ProcessTree`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "ProcessTree"}} /></pre>

Collect resources for the selected root process and all descendants.
