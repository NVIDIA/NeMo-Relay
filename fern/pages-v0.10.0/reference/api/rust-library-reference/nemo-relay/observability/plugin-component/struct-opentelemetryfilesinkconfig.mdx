One local file destination for projected OTLP spans.

A file sink writes the same `ExportTraceServiceRequest` an OTLP endpoint would receive, so a consumer that reads trajectories as artifacts needs no collector. It shares the projection and batching settings with [`OpenTelemetryEndpointConfig`](/reference/api/rust-library-reference/nemo-relay/observability/plugin_component/struct-opentelemetryendpointconfig) and drops the fields that only a network destination has: endpoint, transport, headers, and timeout.

### `otel_type: OpenTelemetryType`

### `output_directory: PathBuf`

Directory containing the output file.

### `filename: Option<String>`

Output filename. Defaults to a timestamped name for the chosen format.

### `format: OtlpFileFormat`

On-disk encoding: `json_lines` or `proto`.

### `mode: String`

File open mode: `append` or `overwrite`.

### `mark_projection: MarkProjection`

Representation used for point-in-time marks.

### `mark_exclude_names: Vec<String>`

Mark names excluded from tool projection.

### `promote_metadata_prefixes: Vec<String>`

### `promote_resource_metadata_prefixes: Vec<String>`

Literal root-scope Event metadata prefixes copied to OTLP resource attributes.

Extra resource attributes.

### `service_name: String`

`service.name` resource attribute.

### `service_namespace: Option<String>`

Optional `service.namespace` resource attribute.

### `service_version: Option<String>`

Optional `service.version` resource attribute.

### `instrumentation_scope: String`

Instrumentation scope name.

### `max_queue_size: Option<usize>`

Maximum completed spans buffered before the sink drops new spans.

### `max_export_batch_size: Option<usize>`

Maximum spans written in one batch.

### `scheduled_delay_millis: Option<u64>`

Maximum delay before writing a non-full batch, in milliseconds.

### `completed_span_context_ttl_millis: Option<u64>`

How long completed scopes retain trace context for late marks, in milliseconds.
