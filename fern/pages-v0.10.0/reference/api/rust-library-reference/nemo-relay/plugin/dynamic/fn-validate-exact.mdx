Validates only the supplied static plugin configuration.

Unlike [`validate`](/reference/api/rust-library-reference/nemo-relay/plugin/dynamic/fn-validate), this does not discover or merge any `plugins.toml` layers. It is intended for component-specific validators whose callers supplied the complete configuration to validate.
