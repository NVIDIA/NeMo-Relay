CPU measurements and CPU limit events.

## Fields

### `user_time: Option<ResourceMeasurement<ResourceMetricValue, DurationUnit>>`

Cumulative user-mode CPU time, in milliseconds by default.

### `system_time: Option<ResourceMeasurement<ResourceMetricValue, DurationUnit>>`

Cumulative system-mode CPU time, in milliseconds by default.

### `total_time: Option<ResourceMeasurement<ResourceMetricValue, DurationUnit>>`

Cumulative user plus system CPU time, in milliseconds by default.

### `consumption_rate: Option<ResourceMeasurement<f64, CpuUnit>>`

CPU capacity consumed, in logical processors by default.

### `throttled_time: Option<ResourceMeasurement<ResourceMetricValue, DurationUnit>>`

Cumulative time during which the owned environment was CPU-throttled.

### `effective_limit: Option<ResourceMeasurement<f64, CpuUnit>>`

Effective CPU capacity, in logical processors by default.

### `some_pressure_stall_time: Option<ResourceMeasurement<ResourceMetricValue, DurationUnit>>`

Cumulative CPU pressure time during which some work was stalled.

### `full_pressure_stall_time: Option<ResourceMeasurement<ResourceMetricValue, DurationUnit>>`

Cumulative CPU pressure time during which all work was stalled.

### `limit_events: Vec<ResourceLimitEventCount>`

CPU resource-limit event counters.
