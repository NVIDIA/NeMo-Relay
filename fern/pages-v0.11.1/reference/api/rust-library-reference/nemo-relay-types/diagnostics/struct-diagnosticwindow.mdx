Fixed-resolution outcome series for the containing component instance.

Batched deltas belong to their observation interval. Edge buckets cannot establish an exact arbitrary rolling interval or reconstruct occurrence times. Refreshing the component does not replace or duplicate this window.

## Fields

### `resolution_millis: DiagnosticNumber`

Duration of each fixed bucket.

### `bucket_capacity: u32`

Configured bucket slots; memory is independent of observation rate.

### `buckets: Vec<DiagnosticWindowBucket>`

Bounded selected aggregates; idle covered intervals may have zero values.

### `coverage: DiagnosticWindowCoverage`

Actual interval and edge limitations.
