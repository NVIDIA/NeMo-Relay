Reads the host override, falling back to a plugin's execution-message default.

The host resolves this once per activation and passes the effective value to its worker. SDKs use [`worker_max_message_bytes_from_env`](/reference/api/rust-library-reference/nemo-relay-worker-proto/fn-worker-max-message-bytes-from-env) to read that value.

## Errors

Returns an error for an invalid override or an out-of-range fallback.
