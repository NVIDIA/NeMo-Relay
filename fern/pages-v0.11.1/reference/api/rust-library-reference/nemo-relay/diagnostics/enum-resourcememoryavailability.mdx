Availability of the latest-memory projection, independent of diagnostic reads.

## Variants

### `Disabled`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Disabled"}} /></pre>

### `AwaitingTarget`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "AwaitingTarget"}} /></pre>

Waiting for a CLI-owned target.

### `NotYetSampled`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "NotYetSampled"}} /></pre>

No collection has completed.

### `Available`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Available"}} /></pre>

A sample is available; inspect its independent staleness flag.

### `Failed`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Failed"}} /></pre>

Latest collection failed; a prior valid sample may remain.

### `Invalidated`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Invalidated"}} /></pre>

Runtime/target or process owner was invalidated.

### `CapacityUnavailable`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "CapacityUnavailable"}} /></pre>

A sample exceeds the bounded projection vocabulary or capacity.

### `Unsupported`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unsupported"}} /></pre>

The collector platform is unsupported.
