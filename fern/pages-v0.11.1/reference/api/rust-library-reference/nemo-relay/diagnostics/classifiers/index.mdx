Producer-owned pure mappings from existing typed errors to catalogue values. Pure classification for the integrated plugin-operation producer.

This adapter never records, formats source errors, infers causes from messages, alters execution behavior, or assigns application health. Producers call it inside lazy recording factories so disabled diagnostics does no extra work.
