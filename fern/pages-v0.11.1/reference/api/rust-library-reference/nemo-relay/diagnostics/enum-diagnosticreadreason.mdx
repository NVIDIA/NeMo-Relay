#[non_exhaustive]pub enum DiagnosticReadReason {
    Disabled,
    QueryDisabled,
    UnsupportedSchema,
    InvalidQuery,
    InvalidCursor,
    Busy,
    SnapshotCapacity,
    InvalidLimits,
    AllocationFailed,
    Internal,

Stable reasons shared by canonical snapshot adapters. These are operation results, never a source health classification or a producer failure code. Include a fallback arm when matching: future releases can add reasons.

## Variants (Non-exhaustive)

### `Disabled`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Disabled"}} /></pre>

Collection was disabled at startup.

### `QueryDisabled`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "QueryDisabled"}} /></pre>

Collection is enabled but snapshot workspaces were disabled.

### `UnsupportedSchema`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "UnsupportedSchema"}} /></pre>

Requested snapshot version is unsupported.

### `InvalidQuery`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidQuery"}} /></pre>

Malformed, oversized, unknown, or inadmissible query input.

### `InvalidCursor`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidCursor"}} /></pre>

Continuation source, selection, or revision no longer matches.

### `Busy`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Busy"}} /></pre>

Core or adapter concurrency permits are temporarily exhausted.

### `SnapshotCapacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "SnapshotCapacity"}} /></pre>

The admitted page cannot fit a required envelope or atomic row.

### `InvalidLimits`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidLimits"}} /></pre>

Invalid startup capacity profile, including arithmetic overflow.

### `AllocationFailed`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "AllocationFailed"}} /></pre>

An admitted allocation could not be reserved.

### `Internal`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Internal"}} /></pre>

An unexpected internal read failure; no original error text is exposed.
