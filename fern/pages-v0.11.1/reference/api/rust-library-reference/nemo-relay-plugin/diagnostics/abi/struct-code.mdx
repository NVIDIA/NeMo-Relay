## Fields

### `kind: u32`

0 = built-in, 1 = extension.

### `outcome: u32`

0 = unspecified, 1 = success, 2 = failure (extension only).

### `name: Bytes`

Built-in canonical name or local extension name.

### `description: Bytes`

Extension description; empty for a built-in.

### `classes: *const Bytes`

Array of canonical failure-class names.

### `class_count: usize`
