Diagnostic operation error. These values never classify plugin execution.

## Variants (Non-exhaustive)

### `Unsupported`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unsupported"}} /></pre>

Host has no compatible native diagnostics extension.

### `Unavailable`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Unavailable"}} /></pre>

Diagnostic adapter backing could not be admitted.

### `Closed`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Closed"}} /></pre>

Activation or registration was closed.

### `PermissionDenied`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "PermissionDenied"}} /></pre>

Host did not grant whole-context read access.

### `Busy`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Busy"}} /></pre>

Re-entrant call or exhausted bounded admission; no automatic retry occurs.

### `Capacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Capacity"}} /></pre>

Registration or request exceeds its capacity.

### `Invalid`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Invalid"}} /></pre>

Input or handle is invalid.

### `Conflict`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Conflict"}} /></pre>

A local component name is already registered.

### `BufferTooSmall`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "BufferTooSmall"}} /></pre>

Caller-owned output buffer is too small.

### `Internal`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Internal"}} /></pre>

Internal adapter failure; acceptance is not safe to retry.

### `Read(DiagnosticReadReason)`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Read(<a href=\"enum-diagnosticreadreason\">DiagnosticReadReason</a>)"}} /></pre>
