Delivery outcome, independent of plugin execution or health.

## Variants

### `Full`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Full"}} /></pre>

The queue cannot accept another submission.

### `Invalid`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Invalid"}} /></pre>

The payload is invalid or exceeds its bound.

### `NotConsumed`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "NotConsumed"}} /></pre>

Explicit host rejection that did not consume a sequence; counted as rejected.

### `Rejected`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Rejected"}} /></pre>

Terminal host rejection; the sequence was consumed.

### `Uncertain`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Uncertain"}} /></pre>

Acceptance could not be recovered; this session cannot replay further.

### `Closed`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Closed"}} /></pre>

The facade has stopped accepting submissions.
