Multi-sink ATOF JSONL exporter config.

When enabled, this section wraps [`crate::atof::AtofExporter`](/reference/api/rust-library-reference/nemo-relay-observability/atof/struct-atofexporter) and writes the raw ATOF event stream to one or more explicitly configured file or stream sinks.

## Fields

### `enabled: bool`

Whether ATOF JSONL export is active.

### `sinks: Vec<AtofSinkSectionConfig>`

Destinations that each receive every raw ATOF event.
