Remote storage handle for ATIF trajectory uploads.

The handle owns a dedicated OS thread that runs a single-threaded tokio runtime. Subscriber callbacks (which run on the runtime that emitted the event) submit uploads over a synchronous channel and block on the reply, so the handle stays safe to drive from any thread regardless of whether the caller is already inside another tokio runtime.
