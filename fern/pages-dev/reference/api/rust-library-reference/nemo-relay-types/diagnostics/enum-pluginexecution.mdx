```rust
#[non_exhaustive]pub enum PluginExecution {
    NativeAbi,
    WorkerProtocol,
}
```

Producer-authored plugin execution mechanism, excluded from counter identity.

Phase-one core activation recording leaves execution unset. These values support later native/worker producer integrations; they do not describe currently implemented automatic collection.

## Variants (Non-exhaustive)

### `NativeAbi`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "NativeAbi"}} /></pre>

The plugin executes through the native ABI.

### `WorkerProtocol`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "WorkerProtocol"}} /></pre>

The plugin executes through the dynamic-worker protocol.
