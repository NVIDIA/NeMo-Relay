Versioned, transport-neutral runtime diagnostic contracts. Portable diagnostic evidence shared by Relay runtimes, tools, and adapters.

These types describe observations rather than readiness or deployment health. They contain no runtime state. Producers enforce resource limits before recording; consumers inspect coverage before interpreting absent evidence.

Potentially growing integers use DiagnosticNumber, encoded as canonical unsigned decimal JSON strings to preserve every u64 value in JavaScript. Numbers, signs, leading zeroes, fractions, whitespace, and values outside u64 are rejected. Unknown object fields support additive evolution. Unknown catalogue names remain opaque in supported envelopes; unsupported schema versions require adapter negotiation.
