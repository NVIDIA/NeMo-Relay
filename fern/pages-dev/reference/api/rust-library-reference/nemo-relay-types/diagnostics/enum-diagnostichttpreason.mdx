Stable reasons for HTTP inspection, including snapshot, access, and lifecycle failures. This is separate from the transport-neutral [`DiagnosticReadReason`](/reference/api/rust-library-reference/nemo-relay-types/diagnostics/enum-diagnosticreadreason). Unknown future reasons must not be inferred from HTTP status alone.
