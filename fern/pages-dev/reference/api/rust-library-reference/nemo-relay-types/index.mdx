Shared data models and runtime contracts for NeMo Relay.

This crate contains DTOs and wire-compatible type definitions used by the runtime and native plugin SDK. It intentionally does not contain runtime registries, dynamic loading, codec implementations, exporters, or process-global state.

- [diagnostics](/reference/api/rust-library-reference/nemo-relay-types/diagnostics): Versioned runtime diagnostic models and inspection wire contracts. Portable diagnostic evidence shared by Relay runtimes, tools, and adapters.
