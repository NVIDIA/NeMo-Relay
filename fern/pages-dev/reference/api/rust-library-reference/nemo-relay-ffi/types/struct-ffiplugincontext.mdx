Opaque plugin registration context.

This wrapper contains a borrowed raw pointer to an `nemo_relay_plugin_host::PluginRegistrationContext`, not an owned heap allocation. It is only valid for the duration of the plugin registration callback that receives it. C callers must not store the pointer, use it after the callback returns, or attempt to free or drop it.

There is intentionally no `nemo_relay_plugin_context_free` function because this FFI wrapper does not own the underlying registration context.
