Normalize application context from borrowed UTF-8 bytes to bounded JSON.

Validates the complete context before returning an owned JSON string of at most 16 KiB. Does not require runtime initialization. The caller must release the result with `nemo_relay_string_free`. On failure, `out` is set to null.

## Safety

`input` must be readable for `input_length` bytes for this call; the library does not retain it. `out` must be non-null and writable. The input length must not exceed `isize::MAX`.
