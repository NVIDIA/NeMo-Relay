Capture a canonical page. Release successful output with nemo_relay_string_free. The optional query is bounded by the core's encoded query byte limit and uses canonical query fields. Failure always leaves `*out` null. A reader/filter does not restrict authority.

## Safety

Reader must be live; out must be writable and non-aliasing. Query must be null or readable through its NUL terminator (up to 4097 bytes). Freed/forged pointers cannot be detected. Native library must remain loaded while handles are live.
