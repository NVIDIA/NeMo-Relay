Inspect a normalized annotation, using NEMO_RELAY_CONTENT_SOURCE_* and NEMO_RELAY_CONTENT_SELECT_* constants. Only SELECT_MESSAGE reads index. Success returns an owned JSON object with ordered parts and text_parts; an absent selection succeeds with a null output. An empty selection of existing content still returns a snapshot. Free a snapshot with nemo_relay_string_free. An invalid selection/index returns InvalidArg. On failure, *out is null and nemo_relay_last_error describes the error on the calling thread.

## Safety

input must be readable through its NUL terminator for the call. out must point to writable pointer storage distinct from input.
