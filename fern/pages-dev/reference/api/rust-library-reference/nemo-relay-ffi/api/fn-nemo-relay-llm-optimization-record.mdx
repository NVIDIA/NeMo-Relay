Record optimization evidence on a borrowed or retained recorder. `accepted` reports whether Relay accepted the record. Rejection does not fail execution.

## Safety

`recorder` must be live, either retained or borrowed from an active callback; `contribution_json` is a valid C string and `accepted` is writable.
