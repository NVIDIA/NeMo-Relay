Borrow the managed stream's collector/finalizer user data from an interceptor continuation. This lets language bindings associate provider sources with their language owner even when a continuation runs on a different native thread. Returns null for a null continuation or absent callback state.

## Safety

Continuation must be live. The returned data is borrowed and may only be accessed while the stream interceptor callback is active. Do not free it.
