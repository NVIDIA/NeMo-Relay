Retain the optimization recorder owned by a manual LLM call handle. The returned recorder has an independent lifetime and must be freed with `nemo_relay_llm_optimization_recorder_free`. Ending the LLM call closes recording. Later records return `accepted = false`.

## Safety

`handle` must be a live LLM handle or null. `out` must be valid writable pointer storage. A non-null output slot is cleared before validation.
