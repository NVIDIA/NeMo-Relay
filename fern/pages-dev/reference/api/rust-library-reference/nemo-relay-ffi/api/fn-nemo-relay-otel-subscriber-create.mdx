Creates an OTLP subscriber with optional TLS file settings.

`tls_json` accepts a JSON object or a null pointer. The object has three optional file paths: `certificate`, `client_certificate`, and `private_key`. Set the client certificate and private key together. `otel_type` is `full`, `gen_ai`, or `openinference`. For network export, `endpoint` is required. Set `transport` to `grpc` or `http_binary`. Header and resource maps are JSON objects with string values. `header_env_json` maps header names to environment variable names. `mark_projection` is `inherit`, `event`, or `tool`. Exclusions and promotion prefixes are JSON string arrays, and mappings are `[{"key":"...","alias":"..."}]`. Null optional strings and JSON pointers select defaults. A zero timeout uses 3,000 milliseconds. `completed_span_context_ttl_millis` must be positive.

Set `output_directory` to select file export instead of network export. Set `filename` to null to use the default name. `format` is `json_lines` (default) or `proto`. `mode` is `overwrite` (default) or `append`. File export uses the same resource, service, projection, and lineage settings. Network settings (`transport`, `endpoint`, headers, timeout, and TLS) are ignored in file mode. In network mode, `filename`, `format`, and `mode` are ignored.

## Safety

Any non-null C strings must be valid and `out` must be non-null.
