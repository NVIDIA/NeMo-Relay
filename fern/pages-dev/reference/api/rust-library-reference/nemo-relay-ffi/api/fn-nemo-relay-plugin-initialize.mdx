Initialize the unified static and dynamic plugin host from core-owned `plugins.toml` discovery.

`additional_plugins_toml` may be null. When supplied it replaces user-file discovery, above programmatic configuration and below the system file. The returned handle owns all activated plugin registrations and runtimes.

## Safety

Input strings and output pointers must be valid, non-overlapping C pointers.
