Creates an OTLP subscriber with optional TLS file settings.

`tls_json` accepts a JSON object or a null pointer. The object has three optional file paths: `certificate`, `client_certificate`, and `private_key`. Set the client certificate and private key together. Refer to [`nemo_relay_otel_log_subscriber_create_v2`](/reference/api/rust-library-reference/nemo-relay-ffi/api/fn-nemo-relay-otel-log-subscriber-create-v2) for the other options.

## Safety

Any non-null C strings must be valid and `out` must be non-null.
