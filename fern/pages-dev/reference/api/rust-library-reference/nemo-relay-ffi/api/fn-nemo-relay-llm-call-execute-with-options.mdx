Choose which middleware stages run for one call. Combine `NEMO_RELAY_SKIP_*` constants with bitwise OR in `skip_stages`. Zero runs all stages. Unknown bits return `NEMO_RELAY_STATUS_INVALID_ARG`. Relay still sanitizes event data, uses codecs, passes trace context, and handles call completion. Nested calls use their own options.

Relay takes ownership of callback data when this function starts. It releases that data even if input validation fails.

## Safety

Use the same pointer and callback rules as the existing execute function. `out` must point to writable storage for the output pointer.
