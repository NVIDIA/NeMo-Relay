Normalize one application-data value within the enclosing context budget.

`maximum_serialized_bytes` must be between one and 16384. The context root and its data object count as two enclosing containers. The caller charges envelope, key and separator bytes separately. On failure, `out` is null. Release a successful result with `nemo_relay_string_free`.

## Safety

`input` must be readable for `input_length` bytes during this call, with length at most `isize::MAX`. `out` must be non-null and writable. The library does not retain the borrowed input.
