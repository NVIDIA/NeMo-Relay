Serialize the current causal parent with an application-supplied root UUID.

Pass null for `root_uuid` to omit the root. The returned JSON must be freed with `nemo_relay_string_free`.

## Safety

When non-null, `root_uuid` must point to a valid NUL-terminated C string; `out` must be a valid, writable pointer to a C-string output slot.
