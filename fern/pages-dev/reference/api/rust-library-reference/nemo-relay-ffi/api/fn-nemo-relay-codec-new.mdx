Create a request codec, response codec, or both. Built-in providers use null callbacks. `NEMO_RELAY_CODEC_CUSTOM` requires at least one codec direction. Request decode and encode must be provided together. Relay owns callback state when the call starts, even if validation fails. It frees the state exactly once after all native references are released. Unknown providers return null and set the last error. Release a successful result with `nemo_relay_codec_free`.

## Safety

Non-null callbacks must point to a valid struct. Callback state must remain valid and thread-safe until its destructor runs. Callback result strings transfer ownership to Relay and must use the Relay string allocator contract.
