Create an isolated scope stack, optionally from propagation-context JSON.

Pass null to create a new root scope. Free the result with `nemo_relay_scope_stack_free`.

## Safety

`context_json` must be null or point to a valid NUL-terminated C string. `out` must be a valid, writable pointer to a scope-stack output slot.
