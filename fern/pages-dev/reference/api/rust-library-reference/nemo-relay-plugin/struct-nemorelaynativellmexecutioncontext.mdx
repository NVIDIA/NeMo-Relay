Codec context passed to native LLM execution intercept callbacks.

The context and codec IDs are borrowed for the callback. A synchronous streaming callback may retain the request codec pointer only in the state of its returned [`NemoRelayNativeLlmStreamV1`](/reference/api/rust-library-reference/nemo-relay-plugin/struct-nemorelaynativellmstreamv1); it remains valid until Relay invokes that stream's drop callback. Other raw callbacks must not retain codec pointers. Asynchronous streaming callbacks must instead retain the output stream and use the v7 stream codec functions.
