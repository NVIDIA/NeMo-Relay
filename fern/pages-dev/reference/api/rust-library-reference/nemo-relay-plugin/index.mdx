Shared in-process plugin contracts, stable native ABI, and Rust authoring helpers.

This crate intentionally does not depend on the `nemo-relay` runtime crate. Native plugins built with it communicate with a host through versioned checked ABI-safe values and foreign futures.

- [component](/reference/api/rust-library-reference/nemo-relay-plugin/component): Shared built-in component contracts. In-process plugin contracts shared by built-in components and runtime hosts.
- [diagnostics](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics): Diagnostic submission and authorized reads. Native diagnostic authoring and explicitly authorized canonical reads. Recording is synchronous, state-only, and independent of operational logs. Disabled/unsupported facades skip factories. Diagnostic errors must not be propagated as plugin execution failures unless the application chooses so.
