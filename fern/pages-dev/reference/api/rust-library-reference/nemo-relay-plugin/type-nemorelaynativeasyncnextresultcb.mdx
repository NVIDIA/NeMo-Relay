Receives one completion from a unary execution-continuation invocation.

Exactly one of `value_json` and `error` is non-null. The callback owns its `user_data` and is invoked exactly once after a successful `async_next_invoke_result` call, including when the owning interceptor settles and cancels unfinished downstream work. For a tool continuation, `value_json` contains canonical [`ToolExecutionResult`](/reference/api/rust-library-reference/nemo-relay-plugin/struct-toolexecutionresult) JSON.
