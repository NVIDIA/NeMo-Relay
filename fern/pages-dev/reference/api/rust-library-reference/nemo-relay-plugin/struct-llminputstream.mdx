Downstream LLM stream that reports whether its cleanup succeeded.

The stream closes its downstream source when it ends or is dropped, as [`LlmStreamNext::call`](/reference/api/rust-library-reference/nemo-relay-plugin/struct-llmstreamnext) streams do. [`Self::close`](/reference/api/rust-library-reference/nemo-relay-plugin/struct-llminputstream) waits for that cleanup.

A failed cleanup is reported again on later calls rather than retried; component shutdown retries it.
