ABI-v7 host table for context-aware LLM execution intercept callbacks.

The inherited function-pointer table has the same fields as ABI v6, but its LLM execution callback typedefs include [`NemoRelayNativeLlmExecutionContext`](/reference/api/rust-library-reference/nemo-relay-plugin/struct-nemorelaynativellmexecutioncontext). The distinct table version prevents either side from invoking a callback compiled with the old argument layout.
