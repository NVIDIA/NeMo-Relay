Concrete invocation-local context owned by Relay.

Application-defined keys belong under [`Self::data`](/reference/api/rust-library-reference/nemo-relay-worker/struct-applicationexecutioncontext), not at the top level. Relay validates JSON structure and resource limits; middleware defines the meaning, schema and trust policy of application data. `{}` and `{"data":{}}` are distinct valid contexts, both different from omitting context entirely. Use [`Self::try_from`](/reference/api/rust-library-reference/nemo-relay-worker/struct-applicationexecutioncontext) for JSON input or [`Self::default`](/reference/api/rust-library-reference/nemo-relay-worker/struct-applicationexecutioncontext) for typed construction.

## Fields (Non-exhaustive)

### `data: Option<BTreeMap<String, Value>>`

Application-owned JSON object, isolated for each middleware invocation.

Its contents grant no authority by themselves and are never interpreted as built-in Relay fields. Omission differs from an explicitly empty map.
