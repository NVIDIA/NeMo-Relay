Application context for one LLM call.

Put application keys inside [`Self::data`](/reference/api/rust-library-reference/nemo-relay-worker/struct-llmapplicationexecutioncontext). Relay checks the JSON structure and resource limits. Middleware defines and checks the contents of `data`. No context, `{}`, and `{"data":{}}` are three different values. Use [`Self::try_from`](/reference/api/rust-library-reference/nemo-relay-worker/struct-llmapplicationexecutioncontext) to read JSON input. Use [`Self::default`](/reference/api/rust-library-reference/nemo-relay-worker/struct-llmapplicationexecutioncontext) to create an empty context.

## Fields (Non-exhaustive)

### `data: Option<BTreeMap<String, Value>>`

Application JSON object. Each middleware call gets its own copy.

Relay does not treat these keys as built-in fields or as permission to perform an action. Omitting data differs from passing an empty map.
