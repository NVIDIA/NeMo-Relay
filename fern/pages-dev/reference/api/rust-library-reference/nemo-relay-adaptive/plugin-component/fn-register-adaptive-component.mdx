Registers the adaptive component kind in the core plugin registry.

SDKs and the CLI register this automatically. Custom embeddings may call this before validating or initializing adaptive components.

## Returns

A core plugin [`Result`](/reference/api/rust-library-reference/nemo-relay-plugin-host/type-result) that is `Ok(())` when the adaptive component kind is available in the registry.

## Errors

Returns an error if an external plugin already owns the reserved kind. Re-registering a built-in component is idempotent.
