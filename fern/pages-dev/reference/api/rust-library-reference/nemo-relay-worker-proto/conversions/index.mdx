Typed domain conversions for the namespaced worker contract. Typed conversions between shared domain values and protobuf values.

The host and Rust worker use the same [`WireValue`](/reference/api/rust-library-reference/nemo-relay-worker-proto/conversions/trait-wirevalue) implementations so native and worker callbacks retain the types from `nemo_relay_types`. Generated protobuf types describe transport presence and alternatives separately.

`dto.rs` declares struct fields, enum mappings, and collection wrappers. Matching field names use `field: mode`; renames use `source => target: mode`. Both directions construct every struct field, making omitted mappings a compile-time error. `variants.rs` handles enums and structural differences explicitly. Shared helpers here check required values, integer widths, timestamps, and JSON syntax while preserving native null semantics.

See the crate's `CONTRACT.md`, "Rust domain conversions", for field modes, representation differences, and the maintenance workflow.
