Versioned gRPC protocol for NeMo Relay out-of-process worker plugins.

The [`nvidia_worker_v1`](/reference/api/rust-library-reference/nemo-relay-worker-proto/nvidia_worker_v1) contract models Relay-owned DTOs in protobuf and keeps application/provider fields as lossless JSON.

## Modules

- [conversions](/reference/api/rust-library-reference/nemo-relay-worker-proto/conversions): Typed domain conversions for the namespaced worker contract. Typed conversions between shared domain values and protobuf values.
- [nvidia_worker_v1](/reference/api/rust-library-reference/nemo-relay-worker-proto/nvidia_worker_v1): Typed worker contract introduced alongside the legacy API.
- [validation](/reference/api/rust-library-reference/nemo-relay-worker-proto/validation): Runtime enforcement of the namespaced protobuf contract. Validate shapes, semantic annotations, and the syntax of open JSON values.
