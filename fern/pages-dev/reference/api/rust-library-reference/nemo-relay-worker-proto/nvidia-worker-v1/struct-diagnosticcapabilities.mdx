Host-owned limits and contract identities required for diagnostic admission.

## Fields

### `protocol: Option<ProtocolIdentity>`

Required protocol name and semantic contract version to confirm during handshake.

### `snapshot_contract_version: String`

These transport contracts start at 1.0.0; core catalogue revisions do not.

### `catalogue_version: u32`

Core diagnostic catalogue revision, independent of the worker contract version.

### `enabled: bool`

Whether the host accepts diagnostic recording for this activation.

### `can_read_context: bool`

Whether separately authorized context-wide snapshot reads are granted.

### `max_components: u32`

Host bound on component admission or requested component page size.

### `max_extensions: u32`

Maximum plugin-defined diagnostic extensions admitted in the session.

### `max_metadata_bytes: u32`

Maximum encoded component and code registration metadata admitted by the host.

### `max_request_bytes: u32`

Complete encoded SubmitDiagnosticRequest, including credentials and sequence.

### `max_detail_bytes: u32`

Maximum diagnostic detail bytes permitted by the host.

### `max_correlation_bytes: u32`

Maximum trajectory correlation bytes permitted by the host.

### `max_response_bytes: u32`

Maximum complete encoded diagnostic response size.

### `max_pending_submissions: u32`

Queue capacity excludes the one in-flight submission.

### `retry_attempts: u32`

Maximum submission attempts, including the initial attempt.

### `retry_timeout_duration: Option<Duration>`

Deadline for each diagnostic submission attempt, from one millisecond to ten seconds.

### `provenance_contract_version: String`

Supported authenticated remote-provenance contract version, initially 1.0.0.

### `can_read_discovery: bool`

Grants side-effect-free source discovery only; unsupported or denied is false.

### `can_inspect_memory: bool`

Grants bounded memory inspection only; it never starts resource collection.
