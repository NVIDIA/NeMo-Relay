Known category-specific fields and lossless extensions attached to an event.

## Fields

### `model_name: Option<String>`

Normalized model identifier for LLM events.

### `tool_call_id: Option<String>`

LLM-provider correlation ID for Tool events.

### `subtype: Option<String>`

Vendor subtype required when `category == "custom"`.

### `tool_result_annotation: Option<JsonValue>`

Normalized tool result annotation for successful tool end events.

### `extra: HashMap<String, JsonValue>`

Unknown category-profile keys preserved from newer producers.

### `annotated_request: Option<Box<AnnotatedLlmRequest>>`

Normalized request annotation for LLM start events.

### `annotated_response: Option<Box<AnnotatedLlmResponse>>`

Normalized response annotation for LLM end events.

### `time_to_first_chunk_seconds: Option<f64>`

Elapsed seconds from managed stream execution to its first received chunk.
