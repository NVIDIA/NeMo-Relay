Optional provider token counts and cost; absent counts never imply zero.

## Fields

### `prompt_tokens: Option<u64>`

Tokens consumed by the prompt/input.

### `completion_tokens: Option<u64>`

Tokens generated in the completion/output.

### `total_tokens: Option<u64>`

Total tokens (prompt + completion).

### `cache_read_tokens: Option<u64>`

Tokens served from prompt cache (read).

### `cache_write_tokens: Option<u64>`

Legacy aggregate prompt-cache write count; use cache_write_token_counts when present.

### `cache_write_1h_tokens: Option<u64>`

Legacy one-hour subset of the aggregate prompt-cache write count.

### `uncached_input_tokens: Option<u64>`

Input tokens neither read from nor written to the provider's prompt cache. Include this value only when the provider's usage rules define this split. Absence does not mean zero.

### `cost: Option<CostEstimate>`

Optional cost reported by provider data or estimated from Relay model pricing.

### `cache_write_token_counts: Option<CacheWriteTokenCountsList>`

Ordered duration-aware cache writes; presence overrides both legacy cache-write fields.
