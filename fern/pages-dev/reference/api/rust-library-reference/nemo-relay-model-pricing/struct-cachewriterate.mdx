Prompt cache write price for one cache duration.

## Fields

### `duration: Option<u64>`

Cache duration in seconds, as reported in `CacheWriteTokenCounts::duration`. An entry with no duration is the default for writes with no matching entry.

### `per_million: f64`

Price per one million tokens.
