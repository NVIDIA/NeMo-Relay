Per-provider streaming codec used with the runtime streaming execution API.

`collector()` and `finalizer()` produce owned closures that share the codec's internal accumulation state. Implementations typically wrap that state in `Arc<Mutex<...>>` so each `&self`-produced closure captures a clone of the handle.

[`LlmFinalizerFn`](/reference/api/rust-library-reference/nemo-relay/middleware/type-llmfinalizerfn) is `FnOnce`, so a [`StreamingCodec`](/reference/api/rust-library-reference/nemo-relay/trait-streamingcodec) instance is single-use: callers construct a fresh instance per managed-lifecycle call and discard it after the stream completes.
