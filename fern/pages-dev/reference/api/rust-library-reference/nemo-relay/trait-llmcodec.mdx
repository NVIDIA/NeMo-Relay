A bidirectional translator between opaque [`LlmRequest`](/reference/api/rust-library-reference/nemo-relay/struct-llmrequest) content and structured [`AnnotatedLlmRequest`](/reference/api/rust-library-reference/nemo-relay/struct-annotatedllmrequest).

Codecs are implemented by framework integrations and provider adapters because each SDK has its own request format. A codec is supplied per call by the caller; the built-in provider codecs can also be selected from a raw payload by the runtime provider resolver.

## Design

- **Synchronous**: `decode`/`encode` are pure data transforms (JSON restructuring), not I/O operations. This matches existing guardrails and request intercepts.
- **`Send + Sync`**: Required for codec handles shared across async runtime contexts.
- **Trait object**: Codecs are registered at runtime by callers or bindings, so the Rust core cannot know concrete types at compile time. Store as `Arc<dyn LlmCodec>`.

#### `encode`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "fn encode(\n    &amp;self,\n    annotated: &amp;<a href=\"struct-annotatedllmrequest\">AnnotatedLlmRequest</a>,\n    original: &amp;<a href=\"struct-llmrequest\">LlmRequest</a>,\n) -&gt; <a href=\"https://doc.rust-lang.org/1.96.1/core/result/enum.Result.html\">Result</a>&lt;<a href=\"struct-llmrequest\">LlmRequest</a>, <a href=\"enum-flowerror\">FlowError</a>&gt;"}} /></pre>

Merge structured changes back into the opaque request.

The `original` parameter is the pre-intercept [`LlmRequest`](/reference/api/rust-library-reference/nemo-relay/struct-llmrequest), used to preserve fields that the Codec does not structurally model. Implementations MUST use merge-not-replace semantics: overlay structured changes onto the original content, do not construct a fresh content object.

Return this codec's identity for LLM sanitizer context.

Custom codecs should keep the default [`LlmCodecIdentity::Opaque`](/reference/api/rust-library-reference/nemo-relay/middleware/enum-llmcodecidentity) unless they have a stable runtime registration ID. Callers must not infer a provider surface from an opaque implementation or request shape.

#### `encode_with_baseline`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "fn encode_with_baseline(\n    &amp;self,\n    annotated: &amp;<a href=\"struct-annotatedllmrequest\">AnnotatedLlmRequest</a>,\n    original: &amp;<a href=\"struct-llmrequest\">LlmRequest</a>,\n    _baseline: &amp;<a href=\"struct-annotatedllmrequest\">AnnotatedLlmRequest</a>,\n) -&gt; <a href=\"https://doc.rust-lang.org/1.96.1/core/result/enum.Result.html\">Result</a>&lt;<a href=\"struct-llmrequest\">LlmRequest</a>, <a href=\"enum-flowerror\">FlowError</a>&gt;"}} /></pre>

Merge changes using the annotation decoded from `original.content`.

Use a baseline from this codec and the same raw request body. Do not change the baseline or that body after decoding. Request headers can change while middleware runs. The runtime supplies this baseline to avoid decoding twice. The default calls [`Self::encode`](/reference/api/rust-library-reference/nemo-relay/trait-llmcodec), so existing custom codecs still work.

#### `encode_owned_with_baseline`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "fn encode_owned_with_baseline(\n    &amp;self,\n    annotated: &amp;<a href=\"struct-annotatedllmrequest\">AnnotatedLlmRequest</a>,\n    original: <a href=\"struct-llmrequest\">LlmRequest</a>,\n    baseline: &amp;<a href=\"struct-annotatedllmrequest\">AnnotatedLlmRequest</a>,\n) -&gt; <a href=\"https://doc.rust-lang.org/1.96.1/core/result/enum.Result.html\">Result</a>&lt;<a href=\"struct-llmrequest\">LlmRequest</a>, <a href=\"enum-flowerror\">FlowError</a>&gt;"}} /></pre>

Encode a request that the caller gives to this codec.

The codec can move the request body or keep it for later use. The baseline must match the original request body. If both header maps have the same key, keep the value from the original request. The default calls [`Self::encode_with_baseline`](/reference/api/rust-library-reference/nemo-relay/trait-llmcodec) and then moves the original headers into the result.
