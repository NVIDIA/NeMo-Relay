Plugin contracts, configuration, and activation.

Verified-artifact activation is provided by `nemo-relay-plugin-host`:

```rust
use nemo_relay::plugin::initialize_with_verified_specs;
```

Use `initialize` for configuration-selected process diagnostics or `initialize_with_diagnostics` to inject an application-owned service. Exact activation is provided by `nemo-relay-plugin-host`:

```rust
use nemo_relay::plugin::initialize_exact;
```

Initialize through the functions in this module so the SDK composes its built-in plugins before validation and activation. Host-only constructors are not available on the returned handle:

```rust
use nemo_relay::plugin::{PluginConfig, PluginHostActivation};
async fn bypass_composition() {
    let _ = PluginHostActivation::initialize_exact(PluginConfig::default()).await;
}
```
