Initializes the plugin host using an explicitly selected diagnostic context.

Configuration inheritance and common component activation use this same context. Discovery and validation APIs do not consume the process default. Diagnostic admission is best-effort and never changes plugin execution or legacy report results. Native/worker producer integration remains separate.
