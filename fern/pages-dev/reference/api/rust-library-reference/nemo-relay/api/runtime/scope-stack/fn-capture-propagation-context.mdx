Capture the current causal parent without asserting a session root.

Importing the returned context preserves Relay event parentage but starts a new local OpenTelemetry trace. Use [`capture_propagation_context_with_root`](/reference/api/rust-library-reference/nemo-relay/api/runtime/scope_stack/fn-capture-propagation-context-with-root) when the receiver should participate in a Relay-derived trace rooted at a stable application UUID.
