Bounded, process-local diagnostic evidence, independent of logger startup.

Startup composition chooses collection once. Disabled handles skip lazy work; enabled components reserve summaries before recording. Recent evidence uses a shared circular history and a reclaimable detail pool. Neither history loss nor output delivery changes accepted numeric totals. Diagnostic evidence never assigns readiness, recovery, or deployment health.

The backing-storage budget excludes caller-owned inputs, producer handles, independently decoded snapshot copies, allocator overhead, and user callback captures. Existing operational output and legacy reports have separate budgets.

## Startup and recording

Select settings once before giving producers their handles. Install the chosen context with [`Diagnostics::install_process_default`](/reference/api/rust-library-reference/nemo-relay/diagnostics/struct-diagnostics) before using convenience constructors, or inject it explicitly into logging and plugin composition. Neither path requires logging to initialize first.

```rust
use nemo_relay::diagnostics::*;

let diagnostics = Diagnostics::from_settings(
    SourceIdentity {
        instance_id: uuid::Uuid::now_v7(),
        process_id: Some(std::process::id()),
        process_role: "embedded".into(),
        relay_version: env!("CARGO_PKG_VERSION").into(),
    },
    DiagnosticsSettings { enabled: true, ..Default::default() },
)?;
let code = BuiltinDiagnosticCode::Failure(FailureCode::Logging(LoggingFailureCode::SinkWriteFailed));
let recorder = diagnostics.register_component(ComponentRegistration::new("example", &[code]))?;
recorder.record_lazy(|| Observation::new(
    Classification::failure(FailureCode::Logging(LoggingFailureCode::SinkWriteFailed), FailureClass::Io)
        .expect("supported catalogue pair"),
    "Producer-approved safe detail",
    std::num::NonZeroU64::MIN, // occurrence delta, never a cumulative total
))?;
let page = diagnostics.snapshot(&DiagnosticQuery::default())?;
let bounded_json: &[u8] = page.as_bytes();
```

Disabled contexts use the same producer calls and skip their lazy factories; reads return [`DiagnosticError::Disabled`](/reference/api/rust-library-reference/nemo-relay/diagnostics/enum-diagnosticerror). Held snapshot leases use a reserved query workspace until dropped. Decoding [`SnapshotLease::to_snapshot`](/reference/api/rust-library-reference/nemo-relay/diagnostics/struct-snapshotlease) instead creates an independent caller-owned DTO outside the service's memory budget.
