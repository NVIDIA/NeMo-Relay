}

Semantic family of related plugin diagnostic codes.

Family is derived from a code's catalogue ownership. Execution mechanism is separately supplied by producers through [`PluginExecution`](/reference/api/rust-library-reference/nemo-relay/diagnostics/enum-pluginexecution).

## Variants (Non-exhaustive)

### `Common`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Common"}} /></pre>
