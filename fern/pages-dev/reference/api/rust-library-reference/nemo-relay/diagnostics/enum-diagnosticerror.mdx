Validation, admission, or availability failure, independent of operational logging.

## Variants

### `Disabled`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Disabled"}} /></pre>

Reads report configured disablement instead of available empty evidence.

### `InvalidLimits`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidLimits"}} /></pre>

Enabled capacities are invalid, overflow arithmetic, or exceed the byte ceiling.

### `Allocation`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Allocation"}} /></pre>

An admitted startup backing allocation could not be reserved.

### `InvalidComponentKey`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidComponentKey"}} /></pre>

The logical key is empty, oversized, or outside the supported syntax.

### `InvalidCode`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidCode"}} /></pre>

The code is undeclared or its handle names another/stale registration.

### `InvalidClassification`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidClassification"}} /></pre>

The code or extension does not permit the supplied cause.

### `InvalidContext`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidContext"}} /></pre>

Plugin context contains a name unsupported by this recording runtime.

### `ComponentCapacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "ComponentCapacity"}} /></pre>

Admission cannot fit another component without displacing active state.

### `KeyCapacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "KeyCapacity"}} /></pre>

Declared built-in or extension counter reservations cannot fit.

### `MetadataCapacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "MetadataCapacity"}} /></pre>

A key, ownership value, or descriptor exceeds metadata capacity.

### `WindowCapacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "WindowCapacity"}} /></pre>

The requested outcome series cannot reserve its bucket storage.

### `ComponentClosed`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "ComponentClosed"}} /></pre>

The handle names a closed or replaced registration.

### `SequenceExhausted`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "SequenceExhausted"}} /></pre>

A sequence or generation cannot advance without identity reuse.

### `QueryDisabled`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "QueryDisabled"}} /></pre>

Startup intentionally disabled query materialization with max_queries = 0.

### `QueryCapacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "QueryCapacity"}} /></pre>

Every bounded query workspace is currently leased.

### `InvalidQuery`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidQuery"}} /></pre>

A selector or page request exceeds its admission constraints.

### `InvalidCursor`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "InvalidCursor"}} /></pre>

Continuation has the wrong source/scope or its captured state changed.

### `SnapshotCapacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "SnapshotCapacity"}} /></pre>

A selected atomic row or required envelope cannot fit the query budgets.

### `ProjectionCapacity`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "ProjectionCapacity"}} /></pre>

Subscription slots or unique registration IDs are exhausted.

### `AlreadyInitialized`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "AlreadyInitialized"}} /></pre>

The process context was already installed or consumed, even while disabled.
