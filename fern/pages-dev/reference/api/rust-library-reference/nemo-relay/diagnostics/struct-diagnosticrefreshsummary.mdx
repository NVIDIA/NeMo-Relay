One current resettable counting period, with no retained historical summary.

The generation marks a refresh boundary within a component instance. Ownership describes this current period; it does not relabel the component lifetime totals. Totals count observations recorded after the refresh boundary, including work carrying an older captured origin, and evictions performed after the boundary.

## Fields

### `generation: DiagnosticNumber`

Component-local generation increased by a successful refresh.

### `started_at: DateTime<Utc>`

Wall-clock correlation anchor for the successful refresh.

### `elapsed_millis: DiagnosticNumber`

Monotonic elapsed duration since the refresh boundary.

### `ownership: ComponentOwnership`

Current configuration and owner attribution for this counting period.

### `totals: DiagnosticTotals`

Counts for this current period, independently reserved from lifetime totals.
