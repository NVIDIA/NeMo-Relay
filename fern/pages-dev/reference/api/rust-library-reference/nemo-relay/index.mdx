The public Rust SDK for NeMo Relay.

Instrument through [`scope`](/reference/api/rust-library-reference/nemo-relay/scope), [`tool`](/reference/api/rust-library-reference/nemo-relay/tool), and [`llm`](/reference/api/rust-library-reference/nemo-relay/llm), register middleware through [`registry`](/reference/api/rust-library-reference/nemo-relay/registry), and observe events through [`subscriber`](/reference/api/rust-library-reference/nemo-relay/subscriber) or [`exporter`](/reference/api/rust-library-reference/nemo-relay/exporter). Shared request, response, error, and codec contracts are re-exported directly. Bindings and component implementations use their owning crates and the execution engine in `nemo-relay-runtime` instead of depending on this SDK.
