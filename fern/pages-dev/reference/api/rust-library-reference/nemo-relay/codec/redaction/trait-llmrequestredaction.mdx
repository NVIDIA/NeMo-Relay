Optional request redaction operations exposed by the active request codec.

Detection and policy belong to the caller. Implementations own provider layout, edit provenance, and validation. Each operation may independently return `Ok(None)` when unsupported; callers must omit the payload on failure.

Return a payload only when all edits can be represented without moving values onto unrelated source parts. Reject ambiguous or uncovered edits.

#### `project_request`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "fn project_request(\n    &amp;self,\n    _sanitized: &amp;<a href=\"../../struct-annotatedllmrequest\">AnnotatedLlmRequest</a>,\n) -&gt; <a href=\"https://doc.rust-lang.org/1.96.1/core/result/enum.Result.html\">Result</a>&lt;<a href=\"https://doc.rust-lang.org/1.96.1/core/option/enum.Option.html\">Option</a>&lt;<a href=\"../../struct-llmrequest\">LlmRequest</a>&gt;, <a href=\"../../enum-flowerror\">FlowError</a>&gt;"}} /></pre>

Construct clean provider output solely from approved sanitized data.

Unlike ordinary `encode`, this operation has no original wire payload. Never restore original fields or consult retained per-call source data. The caller must remove or sanitize opaque extras, native payloads, and tool payloads before approval. Return no original request headers.
