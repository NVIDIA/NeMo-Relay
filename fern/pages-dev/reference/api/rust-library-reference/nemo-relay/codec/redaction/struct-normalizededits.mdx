A sanitized serialized annotation, with positions anchored to its baseline.

Both values use the codec's normalized schema. `baseline` must come from decoding the supplied original payload with that same codec. Sanitizers must preserve array lengths and order: a removed array entry becomes `null`, while a removed object field is absent. Do not compact arrays before this handoff. Codecs must reject mismatched baselines and edits they cannot safely map. These coordinates apply only to this operation; they are not stable handles.

## Fields

### `baseline: &'a Value`

Original normalized annotation, before sanitization.

### `sanitized: &'a Value`

Sanitized annotation, retaining original array slots.

### `require_complete_output: bool`

Whether the policy covers output content or provider-specific output.

Set this even when no matching field exists in the first normalized result. A response codec must reject unmodeled alternatives it cannot cover. Request editing ignores this flag.
