Optional response editing and clean projection exposed by a response codec.

Implementations must account for content outside the normalized result (for example, additional choices), or reject edits that could leave it unsanitized. Unsupported operations default to omission, independently of codec identity.

No original provider payload or retained per-call source data may be used. Exclude opaque extras, native payloads, and tool payloads; callers approve portable fields before invoking this operation.
