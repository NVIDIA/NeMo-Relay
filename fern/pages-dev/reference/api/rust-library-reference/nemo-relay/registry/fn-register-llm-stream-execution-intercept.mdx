Register a global streaming LLM execution intercept. Execution intercepts can wrap or replace the streaming provider callback.

## Parameters

- `name`: Unique middleware name in the global registry.
- `priority`: Lower values run earlier in the chain.
- `callable`: Execution intercept callback stored under `name`.

## Returns

A [`Result`](/reference/api/rust-library-reference/nemo-relay/type-result) that is `Ok(())` when the intercept was registered.

## Errors

Returns [`FlowError::AlreadyExists`](/reference/api/rust-library-reference/nemo-relay/enum-flowerror) when the name is already in use or an internal error if the runtime state cannot be updated.
