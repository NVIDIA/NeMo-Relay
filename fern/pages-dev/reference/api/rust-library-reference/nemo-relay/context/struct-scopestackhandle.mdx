A shared scope-stack identity, without access to the runtime's locks or registries.

Cloning shares the stack. Use [`fork_scope_stack`](/reference/api/rust-library-reference/nemo-relay/context/fn-fork-scope-stack) for independent child work and [`Self::snapshot`](/reference/api/rust-library-reference/nemo-relay/context/struct-scopestackhandle) for read-only inspection.

```rust
let stack = nemo_relay::context::create_scope_stack();
let _ = stack.write();
```

```rust
let stack = nemo_relay::context::create_scope_stack();
let _ = stack.0;
```
