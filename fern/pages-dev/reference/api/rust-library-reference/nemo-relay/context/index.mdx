Task, thread, and distributed request context propagation. Opaque scope ownership and propagation across tasks and threads.

## Functions

- [capture_propagation_context](/reference/api/rust-library-reference/nemo-relay/context/fn-capture-propagation-context): Capture the current causal parent and its Relay root when available.
- [capture_propagation_context_with_root](/reference/api/rust-library-reference/nemo-relay/context/fn-capture-propagation-context-with-root): Capture the current causal parent and an application-supplied session root. Without an imported W3C parent, the supplied root determines the receiver's trace. An imported W3C parent retains precedence over the Relay root. Passing `None` has the same behavior as [`capture_rootless_propagation_context`](/reference/api/rust-library-reference/nemo-relay/context/fn-capture-rootless-propagation-context).
- [capture_rootless_propagation_context](/reference/api/rust-library-reference/nemo-relay/context/fn-capture-rootless-propagation-context): Capture the current causal parent without a root UUID.
- [capture_thread_scope_stack](/reference/api/rust-library-reference/nemo-relay/context/fn-capture-thread-scope-stack): Capture the current thread binding for later restoration.
- [capture_traceparent](/reference/api/rust-library-reference/nemo-relay/context/fn-capture-traceparent): Capture the current canonical W3C `traceparent` value.
- [create_scope_stack](/reference/api/rust-library-reference/nemo-relay/context/fn-create-scope-stack): Create an independent stack containing one implicit root scope.
- [create_scope_stack_from_propagation](/reference/api/rust-library-reference/nemo-relay/context/fn-create-scope-stack-from-propagation): Create an independent stack below a transported causal parent.
- [current_scope_stack_snapshot](/reference/api/rust-library-reference/nemo-relay/context/fn-current-scope-stack-snapshot): Return detached identities from the calling context's explicitly active stack.
- [fork_scope_stack](/reference/api/rust-library-reference/nemo-relay/context/fn-fork-scope-stack): Create an independent child stack below the current causal parent.
- [propagate_scope_to_thread](/reference/api/rust-library-reference/nemo-relay/context/fn-propagate-scope-to-thread): Capture the active stack for propagation to another thread.
- [restore_thread_scope_stack](/reference/api/rust-library-reference/nemo-relay/context/fn-restore-thread-scope-stack): Restore a captured thread binding and its managed-event context.
- [set_thread_scope_stack](/reference/api/rust-library-reference/nemo-relay/context/fn-set-thread-scope-stack): Install a stack on the current thread.
- [snapshot_scope_stack](/reference/api/rust-library-reference/nemo-relay/context/fn-snapshot-scope-stack): Copy a stack into an isolated emission-time snapshot.
- [with_scope_stack](/reference/api/rust-library-reference/nemo-relay/context/fn-with-scope-stack): Run synchronous work with a stack, restoring the previous binding afterward.
- [with_task_scope_stack](/reference/api/rust-library-reference/nemo-relay/context/fn-with-task-scope-stack): Run a future with a stack bound across executor thread switches.
