Register a scope-local lifecycle event subscriber.

The subscriber remains active only while the target scope is still present on the active scope stack.

## Parameters

- `scope_uuid`: UUID of the owning scope.
- `name`: Unique subscriber name within the owning scope.
- `callback`: Subscriber callback invoked for events emitted under that scope hierarchy.

## Returns

A [`Result`](/reference/api/rust-library-reference/nemo-relay/type-result) that is `Ok(())` when the subscriber was registered.

## Errors

Returns [`FlowError::NotFound`](/reference/api/rust-library-reference/nemo-relay/enum-flowerror) when the scope does not exist on the active stack and [`FlowError::AlreadyExists`](/reference/api/rust-library-reference/nemo-relay/enum-flowerror) when the scope already owns a subscriber with the same name.

## Notes

Scope-local subscribers are removed automatically when the owning scope is popped. Native event-producing APIs enqueue subscriber work and return without waiting for callbacks.
