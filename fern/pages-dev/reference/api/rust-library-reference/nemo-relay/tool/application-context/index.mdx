Structured application context and its shared JSON Schema. Concrete Relay execution context with a separate application-owned data map.

JSON Schema validation establishes structure, never approval authenticity. Middleware owns application-data schemas and trust decisions. Application keys cannot collide with future fields of the outer Relay-owned context.
