Process-global access to the shared runtime context state.

The public API layer uses this module to resolve the single [`NemoRelayContextState`](/reference/api/rust-library-reference/nemo-relay-runtime/api/runtime/state/struct-nemorelaycontextstate) instance that owns middleware registrations and runtime extensions for the current process.
