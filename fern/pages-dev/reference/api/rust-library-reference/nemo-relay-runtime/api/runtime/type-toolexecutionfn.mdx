Wrap or replace tool execution with access to the full call context.

The argument payload is carried on the context rather than passed separately, and the managed `tool_call_id` is available.

## Parameters

- First argument: Per-call [`ToolExecutionContext`](/reference/api/rust-library-reference/nemo-relay-runtime/api/runtime/struct-toolexecutioncontext).
- Second argument: Continuation for the remaining execution chain.

## Returns

A future resolving to the canonical tool execution outcome, containing the tool result and any pending lifecycle marks produced by this intercept.

## Errors

The future resolves to an error when the intercept or remaining execution chain fails.
