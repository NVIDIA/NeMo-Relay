Continuation type invoked by tool execution intercepts.

Execution intercepts receive this callable as their `next` continuation and can call it with modified arguments, wrap it, or skip it entirely.

## Parameters

- First argument: JSON argument payload to pass to the remaining execution chain.

## Returns

A future resolving to the downstream tool result and optional opaque annotation. Pending marks from downstream intercepts are retained by the runtime and are not exposed through this continuation.

## Errors

The future resolves to an error when the remaining execution chain fails.

## Lifetime

This continuation can be called repeatedly or concurrently while its execution-intercept callback is still running. Each invocation receives an isolated snapshot of the scopes visible when `next` is called. Calls that remain unfinished or begin after the interceptor settles are rejected.
