Choose which middleware stages run for one managed call.

All stages run by default and keep their usual order. Nested calls use their own options. These options do not change middleware registrations. Relay still sanitizes event data, uses codecs, passes trace context, and handles call completion. Turning off conditional execution skips its checks.

## Fields

### `conditional_execution: bool`

Evaluate conditional-execution guardrails on the original input.

### `request_intercepts: bool`

Apply registered request intercepts before execution.

### `execution_intercepts: bool`

Wrap the callback in registered execution intercepts. Streaming LLM calls use streaming execution intercepts.
