A named registry that maintains a sorted order by priority.

Items are stored by their embedded [`RegistryEntry::name`](/reference/api/rust-library-reference/nemo-relay-runtime/registry/trait-registryentry) value and sorted by [`RegistryEntry::priority`](/reference/api/rust-library-reference/nemo-relay-runtime/registry/trait-registryentry). The sort is performed eagerly: every [`register`](/reference/api/rust-library-reference/nemo-relay-runtime/registry/struct-sortedregistry) or [`deregister`](/reference/api/rust-library-reference/nemo-relay-runtime/registry/struct-sortedregistry) call re-sorts immediately, so [`sorted_values`](/reference/api/rust-library-reference/nemo-relay-runtime/registry/struct-sortedregistry) is a read-only lookup.

Clones share immutable storage. A successful mutation copies shared storage, leaving snapshots unchanged; failed mutations keep sharing the original storage.

## Priority ordering

Entries are sorted in **ascending** priority order (lower numbers run first). This means a guardrail with priority `1` executes before one with priority `10`.

## Uniqueness

Names must be unique within a registry. Attempting to [`register`](/reference/api/rust-library-reference/nemo-relay-runtime/registry/struct-sortedregistry) a duplicate name returns an error. Use [`deregister`](/reference/api/rust-library-reference/nemo-relay-runtime/registry/struct-sortedregistry) first to remove an existing entry before re-registering.
