Use these guides to connect [NVIDIA NeMo Relay](https://github.com/NVIDIA/NeMo-Relay)
capabilities to an enterprise deployment goal.
Each guide explains the decisions, configuration, and evidence you need.
An optional [NVIDIA Brev](https://brev.nvidia.com/) example demonstrates the same
process with specific products.

New to Relay? Start with the [Quick Starts](/getting-started/quick-start) for
your integration or the [Agent Runtime Primer](/about-nemo-relay/agent-runtime-primer)
for the scope, event, and plugin model.

Choose a guide from the **User Guides** navigation for the problem you want to
solve. Follow its deployment process, then use the companion example to inspect
that workflow with specific harnesses, models, and services.

## Try the same workflow on Brev

Use the examples to try a representative enterprise workflow with Relay.
The selected harnesses and integrations are example choices. You can use the
same files on a comparable Linux host; no premade Brev Launchable is required.

<Note title="Use a clean example host">
Existing system-wide Relay configuration can affect either example. Use a fresh
VM without managed Relay policy; a virtual environment does not isolate system
plugin configuration.
</Note>

Each guide explains the enterprise deployment process first. A self-contained
**Run the Brev example** section at the end provides provisioning, setup, and
verification instructions for the selected example. Accounts, model access,
and compute charges depend on the products you select.
