Validates and activates `config` layered on top of the discovered `plugins.toml` configuration, so a direct integration sees the same file layering as the gateway. Each file's schema version is validated before layering. Non-default values in `config` win on conflicts, while default `policy` and `enabled` values inherit from a matching file entry and component `config` bodies merge field-by-field. Delegates to [`initialize_plugins_exact`]. Call that function directly when `config` is already fully resolved and every value must be applied exactly.
