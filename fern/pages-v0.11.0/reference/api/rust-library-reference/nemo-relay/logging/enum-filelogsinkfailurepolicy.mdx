```rust
pub enum FileLogSinkFailurePolicy {
    Required,
    Optional,
}
```

Startup policy for an operational file sink.

Only filesystem failures while opening the sink may be optional. Invalid configuration, logger installation, and delivery infrastructure failures always propagate.

## Variants

### `Required`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Required"}} /></pre>

Fail logging initialization when the configured file cannot be opened.

### `Optional`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Optional"}} /></pre>

Disable an unavailable file for this logging runtime's lifetime, without retry or replay.
