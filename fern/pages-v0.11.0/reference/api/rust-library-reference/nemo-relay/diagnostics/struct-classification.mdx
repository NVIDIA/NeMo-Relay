Shared classification payload for producers, projections, and decoded evidence.

Typed constructors validate built-in code/cause pairs and borrow their stable names. Decoded future names remain opaque. Core validates recording input and resolves admitted identifiers before changing counters or retaining evidence. Transport adapters must bound received names before materializing owned data. Private fields prevent mutation after construction. Explicit opaque-name construction and deserialization preserve evidence without asserting validity.

```rust
use nemo_relay_types::diagnostics::{Classification, SuccessCode};
let mut value = Classification::success(SuccessCode::SinkInitialized);
value.canonical_code = "different.name".into();
```
