```rust
pub struct ComponentRecorder { /* private fields */ }
```

Producer capability scoped to one admitted registration.

Clones share its lease; the last recorder drop closes the component. Producers cannot refresh or replace registrations. Disabled recorders have no active identity and skip lazy observation factories.
