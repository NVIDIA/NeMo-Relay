Append-only native diagnostic ABI. All input spans are borrowed for one call. Nonempty spans and output pointers must be valid for their stated size; arrays must be aligned. No callback retains plugin memory. Integer tags are validated.

## Structs

- [Bytes](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/abi/struct-bytes): Borrowed bytes. A null pointer is permitted only for an empty span.
- [Capabilities](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/abi/struct-capabilities): Non-sensitive recording capabilities; no source-wide diagnostic content.
- [Code](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/abi/struct-code): One declaration. Kind 0 selects a built-in; kind 1 declares an extension.
- [NativeDiagnosticsApiV1](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/abi/struct-nativediagnosticsapiv1): Frozen diagnostics callback table. Status 0 means success; other values are defined by `DiagnosticError::from_status`. Read kinds: 0 discovery, 1 snapshot, 2 memory. Read output is caller-owned; `written` is zero on any failure.
- [NativeHostApiV8WithDiagnostics](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/abi/struct-nativehostapiv8withdiagnostics): Size-discovered tail of the unchanged ABI-8 execution table.
- [Observation](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/abi/struct-observation): Borrowed observation. Empty optional strings mean absent values.
- [Receipt](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/abi/struct-receipt): Allocation-free receipt written only after acceptance.
- [Registration](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/abi/struct-registration): Borrowed registration, whose complete vocabulary is admitted together.
