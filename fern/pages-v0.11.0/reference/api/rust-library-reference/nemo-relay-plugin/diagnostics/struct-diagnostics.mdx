Cloneable activation-scoped diagnostic facade. It does not start a service. Clones share four concurrent-call slots and one in-flight read-buffer slot. Same-thread recursion into the same activation returns [`DiagnosticError::Busy`](/reference/api/rust-library-reference/nemo-relay-plugin/diagnostics/enum-diagnosticerror).
