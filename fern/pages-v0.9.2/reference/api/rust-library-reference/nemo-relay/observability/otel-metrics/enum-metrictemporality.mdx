Preferred aggregation temporality for OTLP metrics.

## Variants

### `Cumulative`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Cumulative"}} /></pre>

Accumulate values from process start.

### `Delta`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Delta"}} /></pre>

Export values recorded since the previous collection when supported.

### `LowMemory`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "LowMemory"}} /></pre>

Favor delta aggregation for counters and histograms to reduce memory.
