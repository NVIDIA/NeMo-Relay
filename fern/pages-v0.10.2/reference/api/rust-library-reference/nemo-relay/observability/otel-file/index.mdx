OTLP file export for NeMo Relay Core.

[`OtlpFileSpanExporter`](/reference/api/rust-library-reference/nemo-relay/observability/otel_file/struct-otlpfilespanexporter) writes the same `ExportTraceServiceRequest` the network exporters put on the wire to a local file. [`OtlpFileFormat`](/reference/api/rust-library-reference/nemo-relay/observability/otel_file/enum-otlpfileformat) selects between the OpenTelemetry file-exporter specification's JSON lines and the Collector's length-delimited protobuf.
