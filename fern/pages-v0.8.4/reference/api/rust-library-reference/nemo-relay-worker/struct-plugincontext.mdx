The callback returns a [`ToolExecutionInterceptOutcome`](/reference/api/rust-library-reference/nemo-relay-worker/struct-toolexecutioninterceptoutcome). Calling [`ToolNext::call`](/reference/api/rust-library-reference/nemo-relay-worker/struct-toolnext) continues the chain and returns the downstream [`ToolExecutionResult`](/reference/api/rust-library-reference/nemo-relay-worker/struct-toolexecutionresult); Relay retains downstream pending marks. `ToolNext` may be called repeatedly or concurrently while the callback is active.
