## Variants

### `Complete = 0`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Complete = 0"}} /></pre>

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Pending = 1"}} /></pre>
