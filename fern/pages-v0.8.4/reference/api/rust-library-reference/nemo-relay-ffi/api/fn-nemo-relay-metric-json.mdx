Emit an atomic metric measurement mark from canonical JSON.

`measurements_json` must be a nonempty JSON array using Relay's canonical `MetricMeasurement` shape. Relay validates the complete array before emitting the metric mark.

## Safety

`name` and `measurements_json` must be valid non-null C strings. Optional pointers may be null and otherwise must remain valid for the call.
