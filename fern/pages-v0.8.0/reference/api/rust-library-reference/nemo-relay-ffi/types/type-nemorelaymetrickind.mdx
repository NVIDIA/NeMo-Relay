Integer-backed OpenTelemetry instrument kind for one typed metric measurement.

This is intentionally not a Rust enum because foreign callers can supply any `int32_t` value. Exported functions validate the value before converting it to the core metric kind. Zero is reserved as unspecified so a zero-initialized measurement cannot select a metric kind accidentally.
