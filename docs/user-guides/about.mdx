## Try the same workflow on Brev

Use the examples to try a representative enterprise workflow with Relay.
The selected harnesses and integrations are example choices. You can use the
same files on a comparable Linux host; no premade Brev Launchable is required.

<Warning title="Use a separate host for each example">
The coding-agent example installs system-wide configuration that can affect
other Relay processes on the host. Use a fresh VM for it, or remove that
deployment before trying another example. A separate virtual environment does
not isolate system plugin policy.
</Warning>

Each guide separates **Your deployment** from **Brev example** instructions.
Follow the deployment process with your existing setup, or use the example
panels to see each step in a disposable environment. Accounts, model access,
and compute charges depend on the products you select.


## Example runtimes

Use Python 3.12 for the companion scripts. On Ubuntu, check the explicit
executable: the default `python3` can be older. With uv:

```bash
uv python install 3.12
uv python find 3.12
```

The routing example also uses Node.js 24.13.1+ and pi 0.84.0.
Authenticate providers before allowing time for a run: observability makes one
model request, governance runs two interactive coding sessions, and routing
runs 27 attempts with `--repeat 3`. Use `--repeat 1` for its first check.
