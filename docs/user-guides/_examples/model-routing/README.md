# Routing Models with NeMo Switchyard

The example compares fixed-capable, fixed-efficient, and routed coding tasks using either Claude Code or Codex, the Switchyard native plugin, and NVIDIA-hosted inference. Choose one harness with `--harness claude` or `--harness codex` for the comparison. Acceptance checks and run evidence remain available for failed attempts.

Follow [Run the Brev example](https://docs.nvidia.com/nemo/relay/user-guides/evaluate-model-routing-with-switchyard#run-the-brev-example)
for VM recommendations, prerequisites, installation, authentication, execution,
verification, and cleanup. The guide is the complete walkthrough for these files.
The same files run on an equivalent Linux host.
