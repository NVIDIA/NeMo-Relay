# Deploy Relay Across Organization Coding Agents

The example provisions two independent Linux users, a shared Relay daemon, managed telemetry policy, and either Claude Code or Codex for both users.

Follow [Run the Brev example](https://docs.nvidia.com/nemo/relay/user-guides/govern-coding-agents#run-the-brev-example)
for VM recommendations, prerequisites, installation, authentication, execution,
verification, and cleanup. The guide is the complete walkthrough for these files.
The same files run on an equivalent Linux host.
