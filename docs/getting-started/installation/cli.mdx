Install the latest stable Relay CLI for Claude Code or Codex. The prebuilt
installers do not require a Rust compiler or Python environment.

<Tabs>
<Tab title="Unix shell">
```bash
curl -fsSL https://raw.githubusercontent.com/NVIDIA/NeMo-Relay/main/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
```
</Tab>
<Tab title="Windows PowerShell">
```powershell
irm https://raw.githubusercontent.com/NVIDIA/NeMo-Relay/main/install.ps1 | iex
```
</Tab>
</Tabs>

Check that the executable is available:

```bash
nemo-relay --version
```

The Unix `PATH` command applies to the current shell. The PowerShell installer
updates the Windows user `PATH` and the installing PowerShell process.

With the CLI and your coding agent installed, choose how Relay connects:

## Run for One Session

Launch your agent through Relay for the current session. These commands do not
install a persistent agent integration; the CLI remains installed after the
session ends.

### Claude Code

```bash
nemo-relay claude
```

### Codex

```bash
nemo-relay codex
```

For a first complete example, follow the
[Claude Code](/getting-started/quick-start/claude-code) or
[Codex](/getting-started/quick-start/codex)
quick start.

## Install a Persistent Integration

The persistent gateway reads user and system configuration; quick-start project
files are not selected automatically. Follow
[Prepare Relay Configuration](/nemo-relay-cli/plugin-installation#prepare-relay-configuration)
to copy the exporter and provider settings you need into that configuration
before expecting exported activity.

Run the matching command once to enable Relay across sessions. Then start your
agent normally and Relay loads automatically.

### Claude Code

```bash
nemo-relay install claude-code
```

### Codex

```bash
nemo-relay install codex
```

Restart your coding agent after installation so it loads the integration.
