Add the extra for your framework to an existing Python project. These commands
install the latest stable Relay release and the framework dependencies it needs.
The quick starts include project creation and pin their example versions.

## Google ADK

```bash
uv add "nemo-relay[google-adk]"
```

Continue with the [Google ADK Quick Start](/getting-started/quick-start/google-adk)
or [Google ADK Integration Guide](/supported-integrations/google-adk).

## LangChain

uv add "nemo-relay[langchain]"

## Installation Notes

Run `uv add` in a project with a `pyproject.toml`; run `uv init` first for a new
project. If you use an active virtual environment without project metadata, use
`uv pip install` or `pip install` with the same package extra instead.

Model providers can require additional dependencies and credentials. The LangChain
and Deep Agents quick starts include the `langchain-nvidia` extra for their NVIDIA
model examples. For integration coverage and configuration, use
[Supported Integrations](/supported-integrations/about).
