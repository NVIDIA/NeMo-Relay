Run one local Codex CLI task through NeMo Relay and write its turn, model, and
tool lifecycle to a local ATOF event file.

This path observes local Codex processes. Cloud or remote Codex tasks are only
partially observable because their provider traffic does not cross the local
Relay gateway.

## Prerequisites

- `codex-cli` 0.143.0 or newer
- Inference access: an OpenAI API key, a supported Codex login, or credentials for an OpenAI Responses-compatible gateway
- A trusted Git working directory where Codex is permitted to create a file
- A [supported NeMo Relay CLI platform](/getting-started/installation#supported-platforms)
- Permission to download the NeMo Relay version used by this guide

On Unix, the verification step also uses `jq`; PowerShell uses its built-in JSON parser.

Use Codex's configured model; Relay does not select or require one. For example,
authenticate with `codex login`, or set `OPENAI_API_KEY` for an API-key-backed
Relay-wrapped run. Relay replaces Codex's model provider with its gateway
provider, so `CODEX_API_KEY` or a custom provider's `env_key` alone is insufficient.
A custom gateway must provide the OpenAI Responses
API; configure its credentials, base URL, and model in Codex before wrapping
the run. Also add an `[upstream]` section with
`openai_base_url = "https://YOUR_GATEWAY/v1"` to the Relay `config.toml` below;
Codex's custom base URL is not carried over when Relay replaces its provider.
Refer to [Codex authentication](https://developers.openai.com/codex/auth).

## 1. Install

Install the pinned NeMo Relay CLI release:

<Tabs>
<Tab title="Unix shell">
{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash"],"session":"main","timeout_seconds":600} */}
```bash
curl -fsSL https://raw.githubusercontent.com/NVIDIA/NeMo-Relay/0.10.0/install.sh | NEMO_RELAY_VERSION=0.10.0 sh
export PATH="$HOME/.local/bin:$PATH"
```
</Tab>

<Tab title="Windows PowerShell">
{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["powershell"],"session":"main","timeout_seconds":600} */}
```powershell
$env:NEMO_RELAY_VERSION = '0.10.0'
irm https://raw.githubusercontent.com/NVIDIA/NeMo-Relay/0.10.0/install.ps1 | iex
```
</Tab>
</Tabs>

## 2. Configure

Create a disposable Git repository and permit Codex to write files there:

{/* quickstart-block {"id":"workspace","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":180} */}
```bash
mkdir relay-codex-quickstart
cd relay-codex-quickstart
git init
```

Save and run the remaining files from this directory.

Save this file as `config.toml` in the directory where you will run the agent:

{/* quickstart-block {"id":"config","role":"file","cwd":"relay-codex-quickstart","path":"config.toml"} */}
```toml
[agents.codex]
command = "codex"
```

Save this sibling file as `plugins.toml`:

{/* quickstart-block {"id":"plugins","role":"file","cwd":"relay-codex-quickstart","path":"plugins.toml"} */}
```toml
version = 1

[policy]
unknown_component = "error"
unknown_field = "error"
unsupported_value = "error"

[[components]]
kind = "observability"
enabled = true

[components.config]
version = 4
enable_full_payloads = false

[components.config.atof]
enabled = true

[[components.config.atof.sinks]]
type = "file"
output_directory = "logs"
filename = "events.jsonl"
mode = "overwrite"
```

ATOF output can contain sensitive prompts, responses, tool arguments, and tool
results. Protect `logs/events.jsonl` even when full payload export is disabled.

## 3. Run

From the directory containing both files, run the common validation prompt:

<Tabs>
<Tab title="Unix shell">
{/* quickstart-block {"id":"run","role":"run","cwd":"relay-codex-quickstart","shells":["bash"],"session":"main","timeout_seconds":180} */}
```bash
nemo-relay --config "$PWD/config.toml" codex -- exec --sandbox workspace-write "Use a file-writing tool to create relay-check.txt in the current working directory containing exactly RELAY_QUICKSTART_TOOL_OK. Then reply with RELAY_QUICKSTART_RESPONSE_OK."
```
</Tab>

<Tab title="Windows PowerShell">
{/* quickstart-block {"id":"run","role":"run","cwd":"relay-codex-quickstart","shells":["powershell"],"session":"main","timeout_seconds":180} */}
```powershell
nemo-relay --config (Join-Path $PWD "config.toml") codex -- exec --sandbox workspace-write "Use a file-writing tool to create relay-check.txt in the current working directory containing exactly RELAY_QUICKSTART_TOOL_OK. Then reply with RELAY_QUICKSTART_RESPONSE_OK."
```
</Tab>
</Tabs>

The [workspace-write sandbox](https://learn.chatgpt.com/docs/non-interactive-mode#permissions-and-safety)
permits the marker file in your working directory; it does not disable sandboxing.

To choose a model for this invocation, use
`nemo-relay --config "$PWD/config.toml" codex -- --model MODEL_ID exec --sandbox workspace-write "YOUR_PROMPT"`.
Replace `MODEL_ID` with an ID your provider supports. Put this Codex option
before `exec`, preserving the prompt and sandbox from the command above.

Relay starts a temporary local gateway and injects Codex hooks for this run. It
does not modify your persistent Codex plugin configuration.

## 4. Verify

Success prints `RELAY_QUICKSTART_TOOL_OK` and `RELAY_QUICKSTART_EVENTS_OK`.

<details>
<summary>Run the verification checks</summary>

After the task exits, confirm that Relay wrote the local event stream:

<Tabs>
<Tab title="Unix shell">
{/* quickstart-block {"id":"verify","role":"run","cwd":"relay-codex-quickstart","shells":["bash"],"session":"main","timeout_seconds":180} */}
```bash
jq -eRs 'gsub("^\\s+|\\s+$"; "") == "RELAY_QUICKSTART_TOOL_OK"' relay-check.txt > /dev/null &&
jq -se '
  . as $events |
  def closed($category):
    any($events[]; .kind == "scope" and .scope_category == "end" and
      .category == $category and
      ($category != "custom" or .name == "codex-turn") and . as $end_event |
      any($events[]; .kind == "scope" and .scope_category == "start" and
        .uuid == $end_event.uuid and .name == $end_event.name and
        .category == $end_event.category and .parent_uuid == $end_event.parent_uuid));
  length > 0 and
  all(.[]; .atof_version == "0.1" and (.kind == "scope" or .kind == "mark")) and
  closed("custom") and closed("tool") and closed("llm")
' logs/events.jsonl > /dev/null &&
printf 'RELAY_QUICKSTART_TOOL_OK\nRELAY_QUICKSTART_EVENTS_OK\n'
```
</Tab>

<Tab title="Windows PowerShell">
{/* quickstart-block {"id":"verify","role":"run","cwd":"relay-codex-quickstart","shells":["powershell"],"session":"main","timeout_seconds":180} */}
```powershell
if ((Get-Content .\relay-check.txt -Raw -ErrorAction Stop).Trim() -ne 'RELAY_QUICKSTART_TOOL_OK') {
  throw 'Expected tool-created marker file is missing'
}
$events = @(Get-Content .\logs\events.jsonl -ErrorAction Stop | ForEach-Object { ConvertFrom-Json -InputObject $_ -ErrorAction Stop })
if (-not $events.Count -or @($events | Where-Object {
  $_.atof_version -ne '0.1' -or $_.kind -notin @('scope', 'mark')
}).Count) { throw 'Expected nonempty ATOF 0.1 records' }
foreach ($category in @('custom', 'tool', 'llm')) {
  $paired = @($events | Where-Object {
    $end = $_
    $end.kind -eq 'scope' -and $end.scope_category -eq 'end' -and
    $end.category -eq $category -and
    ($category -ne 'custom' -or $end.name -eq 'codex-turn') -and @($events | Where-Object {
      $_.kind -eq 'scope' -and $_.scope_category -eq 'start' -and
      $_.uuid -eq $end.uuid -and $_.name -eq $end.name -and
      $_.category -eq $end.category -and $_.parent_uuid -eq $end.parent_uuid
    }).Count -gt 0
  })
  if (-not $paired.Count) { throw "Missing paired $category records" }
}
Write-Output 'RELAY_QUICKSTART_TOOL_OK'
Write-Output 'RELAY_QUICKSTART_EVENTS_OK'
```
</Tab>
</Tabs>

Expected output from the verification command:

{/* quickstart-block {"id":"expected","role":"expected","cwd":"relay-codex-quickstart","from":"verify","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_EVENTS_OK
```

These markers confirm the tool-created file and matching start/end records for
custom turn, tool, and LLM work. The agent's final reply should include
`RELAY_QUICKSTART_RESPONSE_OK`; its surrounding wording can vary.

</details>
