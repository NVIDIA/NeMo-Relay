Run one local Codex CLI task through NeMo Relay and write its agent, model, and
tool lifecycle to a local ATOF event file.

This path observes local Codex processes. Cloud or remote Codex tasks are only
partially observable because their provider traffic does not cross the local
Relay gateway.

## Prerequisites

- `codex-cli` 0.143.0 or newer, already authenticated
- NeMo Relay CLI 0.10.0 or newer

Install the latest stable Relay CLI on Linux or macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/NVIDIA/NeMo-Relay/main/install.sh | sh
```

See [Installation](/getting-started/installation#cli) for Python and Windows
installation paths.

## Select Codex

Save this file as `config.toml` in the directory where you will run the agent:

```toml
[agents.codex]
command = "codex"
```

## Enable Observability

Save this sibling file as `plugins.toml`:

```toml
version = 1

[policy]
unknown_component = "error"
unknown_field = "error"
unsupported_value = "error"

[[components]]
kind = "observability"
enabled = true

[components.config]
version = 4
enable_full_payloads = false

[components.config.atof]
enabled = true

[[components.config.atof.sinks]]
type = "file"
output_directory = "logs"
filename = "events.jsonl"
mode = "overwrite"
```

ATOF output can contain sensitive prompts, responses, tool arguments, and tool
results. Protect `logs/events.jsonl` even when full payload export is disabled.

## Run Codex

From the directory containing both files, run:

```bash
nemo-relay --config "$PWD/config.toml" codex -- exec "Inspect this repository and use one tool."
```

Relay starts a temporary local gateway and injects Codex hooks for this run. It
does not modify your persistent Codex plugin configuration.

## Verify the Events

After the task exits, confirm that Relay wrote the local event stream:

```bash
test -s logs/events.jsonl
tail -n 1 logs/events.jsonl | python3 -m json.tool
```
