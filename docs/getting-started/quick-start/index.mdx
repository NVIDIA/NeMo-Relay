Choose the runtime or language you already use. Relay attaches where your
agent, framework, or application owns model requests and tool execution.

<Note icon="circle-info">
Relay has no required or default model. Each guide that makes live
inference requests identifies the credentials and model access it needs.
The application API examples below use local callbacks.
</Note>
