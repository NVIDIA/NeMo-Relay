Choose the runtime or language you already use. Relay attaches where your
agent, framework, or application owns model requests and tool execution.

<Note icon="circle-info">
Relay has no required or default model. Each guide that makes live
inference requests identifies the credentials and model access it needs.
The application API examples below use local callbacks.
</Note>

## Agent Runtimes

When a coding-agent runtime owns invocation, start with
[CLI Basic Usage](/nemo-relay-cli/basic-usage). For persistent Claude Code or
Codex installation, use [Coding Agent Installation](/nemo-relay-cli/plugin-installation).
For agent-owned integrations, refer to
[Supported Integrations](/supported-integrations/about).

## Featured Plugins

For reusable runtime behavior, start with
[Plugin Configuration Files](/configure-plugins/plugin-configuration-files).

## Agent Frameworks

If a framework owns callbacks or tool execution, choose its path in
[Supported Integrations](/supported-integrations/about).
