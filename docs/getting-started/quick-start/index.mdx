## What You Will Verify

Each guide checks the result appropriate to its integration:

- Coding agents create `relay-check.txt` containing `RELAY_QUICKSTART_TOOL_OK`.
- LangChain and Deep Agents invoke a tool and check the model response.
- LangGraph checks a local graph-state result with `RELAY_QUICKSTART_GRAPH_OK`.
- Python, Node.js, and Rust use local tool and model callbacks without API keys.
- Switchyard checks a routed model response and a routing decision event.

Each guide also checks the corresponding lifecycle or routing records in a
local ATOF event file. Expected output is shown in its Verify step.
