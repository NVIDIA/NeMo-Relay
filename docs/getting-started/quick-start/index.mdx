Choose the host or framework you already use. Each quick start enables the
built-in observability plugin, runs one representative workflow, and verifies
local ATOF output. Paths that install a Relay package or plugin pin the
published 0.9.1 release; Hermes uses its native Relay integration.

## What You Will Verify

The agent and framework paths use a common validation contract:

```text
Use one available tool to produce RELAY_QUICKSTART_TOOL_OK. Then include RELAY_QUICKSTART_RESPONSE_OK in your final response.
```

- A tool or workflow produces `RELAY_QUICKSTART_TOOL_OK`.
- The final response contains `RELAY_QUICKSTART_RESPONSE_OK`.
- Relay writes valid JSONL and the example reports
  `RELAY_QUICKSTART_EVENTS_OK`.

The direct application paths produce the same markers without calling an
external model. Each page includes all commands and configuration required for
its first successful run.
