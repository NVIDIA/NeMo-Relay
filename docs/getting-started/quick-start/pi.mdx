Run one local pi task through NeMo Relay and write its agent, model, and tool
lifecycle to a local ATOF event file.

<Warning>
The pi integration is a proof of concept verified against pi 0.84.0. pi can
introduce breaking hook changes in minor releases, so this quick start installs
that exact version.
</Warning>

## Prerequisites

- Node.js 24 or newer
- npm and a configured model provider
- A [supported NeMo Relay CLI platform](/getting-started/installation#supported-platforms)

On Unix, the verification step also uses `jq`; PowerShell uses its built-in JSON parser.

## 1. Install

Install the verified pi and NeMo Relay releases:

<Tabs>
<Tab title="Unix shell">
{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash"],"session":"main","timeout_seconds":600} */}
```bash
npm install --global @earendil-works/pi-coding-agent@0.84.0
curl -fsSL https://raw.githubusercontent.com/NVIDIA/NeMo-Relay/main/install.sh | NEMO_RELAY_VERSION=0.9.1 sh
export PATH="$HOME/.local/bin:$PATH"
```
</Tab>

<Tab title="Windows PowerShell">
{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["powershell"],"session":"main","timeout_seconds":600} */}
```powershell
npm install --global @earendil-works/pi-coding-agent@0.84.0
$env:NEMO_RELAY_VERSION = '0.9.1'
irm https://raw.githubusercontent.com/NVIDIA/NeMo-Relay/main/install.ps1 | iex
```
</Tab>
</Tabs>

Confirm that `pi --version` reports `0.84.0` before continuing.

pi hooks must originate inside the process, so install the Relay extension once
and verify that pi can load it:

{/* quickstart-block {"id":"host-check","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":600} */}
```bash
nemo-relay install pi
nemo-relay doctor pi
```

## 2. Configure

Use a disposable working directory with no existing `logs/events.jsonl` or
`relay-check.txt`. Permit the agent to write files there. For a repeat test,
use another fresh directory so previous output cannot pass the checks.

Save this file as `config.toml` in the directory where you will run the agent:

{/* quickstart-block {"id":"config","role":"file","cwd":".","path":"config.toml"} */}
```toml
[agents.pi]
command = "pi"
```

Save this sibling file as `plugins.toml`:

{/* quickstart-block {"id":"plugins","role":"file","cwd":".","path":"plugins.toml"} */}
```toml
version = 1

[policy]
unknown_component = "error"
unknown_field = "error"
unsupported_value = "error"

[[components]]
kind = "observability"
enabled = true

[components.config]
version = 4
enable_full_payloads = false

[components.config.atof]
enabled = true

[[components.config.atof.sinks]]
type = "file"
output_directory = "logs"
filename = "events.jsonl"
mode = "overwrite"
```

ATOF output can contain sensitive prompts, responses, tool arguments, and tool
results. Protect `logs/events.jsonl` even when full payload export is disabled.

## 3. Run

From the directory containing both files, run the common validation prompt:

<Tabs>
<Tab title="Unix shell">
{/* quickstart-block {"id":"run","role":"run","cwd":".","shells":["bash"],"session":"main","timeout_seconds":180} */}
```bash
nemo-relay --config "$PWD/config.toml" pi -- -p "Use a file-writing tool to create relay-check.txt in the current working directory containing exactly RELAY_QUICKSTART_TOOL_OK. Then reply with RELAY_QUICKSTART_RESPONSE_OK."
```
</Tab>

<Tab title="Windows PowerShell">
{/* quickstart-block {"id":"run","role":"run","cwd":".","shells":["powershell"],"session":"main","timeout_seconds":180} */}
```powershell
nemo-relay --config (Join-Path $PWD "config.toml") pi -- -p "Use a file-writing tool to create relay-check.txt in the current working directory containing exactly RELAY_QUICKSTART_TOOL_OK. Then reply with RELAY_QUICKSTART_RESPONSE_OK."
```
</Tab>
</Tabs>

Relay starts a temporary local gateway and loads the installed extension for
this run.

## 4. Verify

After the task exits, confirm that Relay wrote the local event stream:

<Tabs>
<Tab title="Unix shell">
{/* quickstart-block {"id":"verify","role":"run","cwd":".","shells":["bash"],"session":"main","timeout_seconds":180} */}
```bash
test "$(cat relay-check.txt)" = 'RELAY_QUICKSTART_TOOL_OK' &&
jq -se '
  . as $events |
  def closed($category):
    any($events[]; .kind == "scope" and .scope_category == "end" and
      .category == $category and . as $end |
      any($events[]; .kind == "scope" and .scope_category == "start" and
        .uuid == $end.uuid and .name == $end.name and
        .category == $end.category and .parent_uuid == $end.parent_uuid));
  length > 0 and
  all(.[]; .atof_version == "0.1" and (.kind == "scope" or .kind == "mark")) and
  closed("agent") and closed("tool") and closed("llm")
' logs/events.jsonl > /dev/null &&
printf 'RELAY_QUICKSTART_TOOL_OK\nRELAY_QUICKSTART_EVENTS_OK\n'
```
</Tab>

<Tab title="Windows PowerShell">
{/* quickstart-block {"id":"verify","role":"run","cwd":".","shells":["powershell"],"session":"main","timeout_seconds":180} */}
```powershell
if ((Get-Content .\relay-check.txt -Raw -ErrorAction Stop).Trim() -ne 'RELAY_QUICKSTART_TOOL_OK') {
  throw 'Expected tool-created marker file is missing'
}
$events = @(Get-Content .\logs\events.jsonl -ErrorAction Stop | ForEach-Object { ConvertFrom-Json -InputObject $_ -ErrorAction Stop })
if (-not $events.Count -or @($events | Where-Object {
  $_.atof_version -ne '0.1' -or $_.kind -notin @('scope', 'mark')
}).Count) { throw 'Expected nonempty ATOF 0.1 records' }
foreach ($category in @('agent', 'tool', 'llm')) {
  $paired = @($events | Where-Object {
    $end = $_
    $end.kind -eq 'scope' -and $end.scope_category -eq 'end' -and
    $end.category -eq $category -and @($events | Where-Object {
      $_.kind -eq 'scope' -and $_.scope_category -eq 'start' -and
      $_.uuid -eq $end.uuid -and $_.name -eq $end.name -and
      $_.category -eq $end.category -and $_.parent_uuid -eq $end.parent_uuid
    }).Count -gt 0
  })
  if (-not $paired.Count) { throw "Missing paired $category records" }
}
Write-Output 'RELAY_QUICKSTART_TOOL_OK'
Write-Output 'RELAY_QUICKSTART_EVENTS_OK'
```
</Tab>
</Tabs>

Expected output from the verification command:

{/* quickstart-block {"id":"expected","role":"expected","cwd":".","from":"verify","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_EVENTS_OK
```

These markers confirm the tool-created file and matching start/end records for
agent, tool, and LLM work. The agent's final reply should include
`RELAY_QUICKSTART_RESPONSE_OK`; its surrounding wording can vary. An echoed
prompt alone does not pass verification.
