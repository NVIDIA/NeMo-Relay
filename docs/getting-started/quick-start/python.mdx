## Goal

Instrument one scope, tool call, and LLM call with NeMo Relay, then verify the
result in a local ATOF event file.

## Prerequisites

- Python 3.11 or newer
- `uv`

<Steps toc={true}>

## Install

Create a project and install the pinned published package. In an existing
`uv` project, skip `uv init`.

{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":600} */}
```bash
mkdir relay-python-quickstart
cd relay-python-quickstart
uv init
uv add nemo-relay==0.10.0
```

## Configure

Save the following configuration as `plugins.toml` in your project directory:

{/* quickstart-block {"id":"plugins","role":"file","cwd":"relay-python-quickstart","path":"plugins.toml"} */}
```toml
version = 1

[policy]
unknown_component = "error"
unknown_field = "error"
unsupported_value = "error"

[[components]]
kind = "observability"
enabled = true

[components.config]
version = 4
enable_full_payloads = false

[components.config.atof]
enabled = true

[[components.config.atof.sinks]]
type = "file"
output_directory = "logs"
filename = "events.jsonl"
mode = "overwrite"
```

<Warning>
ATOF output can contain sensitive prompts, responses, tool arguments, and tool
results. Protect `logs/events.jsonl` even when full payload export is disabled.
</Warning>

## Run

Save this file as `quickstart.py` beside `plugins.toml`:

{/* quickstart-block {"id":"program","role":"file","cwd":"relay-python-quickstart","path":"quickstart.py"} */}
```python
import asyncio
import json
from pathlib import Path
from typing import TypedDict

import nemo_relay


class SearchArgs(TypedDict):
    query: str


async def search(args: SearchArgs) -> nemo_relay.ToolExecutionResult[dict[str, str]]:
    return nemo_relay.ToolExecutionResult({"marker": args["query"]})


async def model(request: nemo_relay.LLMRequest) -> dict[str, object]:
    return {"content": "RELAY_QUICKSTART_RESPONSE_OK"}


async def main() -> None:
    async with nemo_relay.plugin.activate({}, "plugins.toml"):
        try:
            with nemo_relay.scope.scope("demo-agent", nemo_relay.ScopeType.Agent) as handle:
                nemo_relay.scope.event(
                    "initialized", handle=handle, data={"binding": "python"}
                )

                tool_result = await nemo_relay.tools.execute(
                    "emit_marker",
                    {"query": "RELAY_QUICKSTART_TOOL_OK"},
                    search,
                    handle=handle,
                )
                llm_result = await nemo_relay.llm.execute(
                    "demo-provider",
                    nemo_relay.LLMRequest(
                        {},
                        {
                            "messages": [
                                {
                                    "role": "user",
                                    "content": "RELAY_QUICKSTART_RESPONSE_OK",
                                }
                            ]
                        },
                    ),
                    model,
                    handle=handle,
                )

                print(tool_result.result["marker"])
                print(llm_result["content"])
        finally:
            await nemo_relay.subscribers.flush_async()

    events = [json.loads(line) for line in Path("logs/events.jsonl").read_text().splitlines()]
    if not events or any(
        not isinstance(event, dict) or event.get("atof_version") != "0.1"
        or event.get("kind") not in {"scope", "mark"}
        for event in events
    ):
        raise RuntimeError("Expected a nonempty ATOF 0.1 event stream")
    starts = {
        event["uuid"]: event for event in events
        if event["kind"] == "scope" and event.get("scope_category") == "start"
    }
    closed = [
        event for event in events
        if event["kind"] == "scope" and event.get("scope_category") == "end"
        and event.get("uuid") in starts
        and all(event.get(key) == starts[event["uuid"]].get(key)
                for key in ("name", "category", "parent_uuid"))
    ]
    if not {"agent", "tool", "llm"} <= {event.get("category") for event in closed}:
        raise RuntimeError("Expected paired agent, tool, and LLM lifecycle records")
    print("RELAY_QUICKSTART_EVENTS_OK")


asyncio.run(main())
```

Run it from the project directory so the relative output path resolves there:

{/* quickstart-block {"id":"run","role":"run","cwd":"relay-python-quickstart","shells":["bash","powershell"],"session":"main","timeout_seconds":180} */}
```bash
uv run python quickstart.py
```

## Verify

The program parses every JSONL record and checks for paired agent, tool, and
LLM lifecycle records before printing, in order:

{/* quickstart-block {"id":"expected","role":"expected","cwd":"relay-python-quickstart","from":"run","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

<Note icon="circle-info">
The event file contains scope, tool, and LLM records in ATOF JSONL format.
</Note>
