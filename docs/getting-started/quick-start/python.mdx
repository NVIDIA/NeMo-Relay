## Goal

Instrument one scope, tool call, and large language model (LLM) call with NeMo Relay, then verify the
result in a local Agent Trajectory Observability Format (ATOF) file.

<Note icon="circle-info">
This example uses local tool and model callbacks. It does not require an
inference key or a live model.
</Note>

## Prerequisites

Before you start, make sure you have:

- Python 3.11 or newer
- `uv`

<Steps toc={true}>

## Install

Create a project and install the NeMo Relay version for these docs.
For an existing `uv` project, run only the `uv add` command from its directory.

{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":600} */}
```bash
mkdir relay-python-quickstart
cd relay-python-quickstart
uv init
uv add nemo-relay==0.11.0
```

Save this file as `quickstart.py` beside `plugins.toml`:

<Code src="_code/python/quickstart.py" language="python" title="quickstart.py" />

{/* quickstart-block {"id":"run","role":"run","cwd":"relay-python-quickstart","shells":["bash","powershell"],"session":"main","timeout_seconds":180} */}
```bash

```

## Verify

The program checks the event file for paired agent, tool, and LLM lifecycle
records. A successful run prints these markers in order:

{/* quickstart-block {"id":"expected","role":"expected","cwd":"relay-python-quickstart","from":"run","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

<Note icon="circle-info">
The file stores ATOF events as newline-delimited JSON (JSONL).
</Note>

</Steps>
