Instrument one scope, tool call, and LLM call with NeMo Relay, then verify the
result in a local ATOF event file.

## Prerequisites

- Python 3.11 or newer
- `uv`

## 1. Install

Create a project and install the verified published package. In an existing
`uv` project, skip `uv init`.

```bash
mkdir relay-python-quickstart
cd relay-python-quickstart
uv init
uv add nemo-relay==0.9.1
```

## 2. Configure

Save the following configuration as `plugins.toml` in your project directory:

```toml
version = 1

[policy]
unknown_component = "error"
unknown_field = "error"
unsupported_value = "error"

[[components]]
kind = "observability"
enabled = true

[components.config]
version = 4
enable_full_payloads = false

[components.config.atof]
enabled = true

[[components.config.atof.sinks]]
type = "file"
output_directory = "logs"
filename = "events.jsonl"
mode = "overwrite"
```

ATOF output can contain sensitive prompts, responses, tool arguments, and tool
results. Protect `logs/events.jsonl` even when full payload export is disabled.

## 3. Run

Save this file as `quickstart.py` beside `plugins.toml`:

```python
import asyncio
import json
from pathlib import Path
from typing import TypedDict

import nemo_relay


class SearchArgs(TypedDict):
    query: str


async def search(args: SearchArgs) -> nemo_relay.ToolExecutionResult[dict[str, str]]:
    return nemo_relay.ToolExecutionResult({"marker": args["query"]})


async def model(request: nemo_relay.LLMRequest) -> dict[str, object]:
    return {"content": "RELAY_QUICKSTART_RESPONSE_OK"}


async def main() -> None:
    async with nemo_relay.plugin.activate({}, "plugins.toml"):
        try:
            with nemo_relay.scope.scope("demo-agent", nemo_relay.ScopeType.Agent) as handle:
                nemo_relay.scope.event(
                    "initialized", handle=handle, data={"binding": "python"}
                )

                tool_result = await nemo_relay.tools.execute(
                    "emit_marker",
                    {"query": "RELAY_QUICKSTART_TOOL_OK"},
                    search,
                    handle=handle,
                )
                llm_result = await nemo_relay.llm.execute(
                    "demo-provider",
                    nemo_relay.LLMRequest(
                        {},
                        {
                            "messages": [
                                {
                                    "role": "user",
                                    "content": "RELAY_QUICKSTART_RESPONSE_OK",
                                }
                            ]
                        },
                    ),
                    model,
                    handle=handle,
                )

                print(tool_result.result["marker"])
                print(llm_result["content"])
        finally:
            await nemo_relay.subscribers.flush_async()

    event_file = Path("logs/events.jsonl")
    if not event_file.is_file() or event_file.stat().st_size == 0:
        raise RuntimeError("Relay event file is missing or empty")
    json.loads(event_file.read_text().splitlines()[-1])
    print("RELAY_QUICKSTART_EVENTS_OK")


asyncio.run(main())
```

Run it from the project directory so the relative output path resolves there:

```bash
uv run python quickstart.py
```

## 4. Verify

The program validates the event file and prints, in order:

```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

The event file contains scope, tool, and LLM records in ATOF JSONL format.
