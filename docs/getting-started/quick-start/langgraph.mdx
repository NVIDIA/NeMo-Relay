## Goal

Run one credential-free LangGraph workflow and write its lifecycle to a local
Agent Trajectory Observability Format (ATOF) file.

Use the recorded parent/child scopes to follow a workflow through its nodes
when debugging execution.

## Prerequisites

Before you start, make sure you have:

- Python 3.11 or newer
- `uv`

<Steps toc={true}>

## Install

Create a project and install the NeMo Relay version for these docs with the
LangGraph extra.
For an existing `uv` project, run only the `uv add` command from its directory.

{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":600} */}
```bash
mkdir relay-langgraph-quickstart
cd relay-langgraph-quickstart
uv init
uv add "nemo-relay[langgraph]==0.11.0"
```

## Run

The example runs one local `emit_marker` graph node, with no inference
request or credentials. `NemoRelayCallbackHandler` records the graph lifecycle,
and the explicit `langgraph-request` scope groups its node activity. Plugin
activation loads `plugins.toml`; flushing finishes writing queued events before
verification. In your project, replace the marker graph with your workflow and
retain the callback, request scope, and activation lifecycle.

Save this file as `quickstart.py` beside `plugins.toml`:

## Verify

The program checks the event file for matching start and end records from the
`emit_marker` graph node. A successful run prints these markers in order:

{/* quickstart-block {"id":"expected","role":"expected","cwd":"relay-langgraph-quickstart","from":"run","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_GRAPH_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

<Tip>
This deterministic path needs no model credentials. After it works, add a model
and tool node to observe a full agent workflow.
</Tip>

### Inspect the Recorded Activity

Print one completed graph node from the event file:

{/* quickstart-block {"id":"inspect","role":"run","cwd":"relay-langgraph-quickstart","shells":["bash","powershell"],"session":"main","timeout_seconds":180} */}
```bash
uv run python -c "
import json
from pathlib import Path
events = [json.loads(line) for line in Path('logs/events.jsonl').read_text().splitlines()]
call = next(event for event in events if event.get('scope_category') == 'end' and event.get('category') == 'agent' and event.get('name') == 'emit_marker')
fields = ('name', 'category', 'category_profile', 'uuid', 'parent_uuid', 'timestamp', 'metadata')
print(json.dumps({key: call.get(key) for key in fields}, indent=2))
"
```

The node is an `agent` scope named `emit_marker`. Its `parent_uuid` links to
the immediate `LangGraph` scope, whose parent is the outer `langgraph-request`
scope. The node's `uuid` pairs its start and end records. `timestamp` records
when each event occurred. This local graph makes no model request; the records
demonstrate workflow structure.
