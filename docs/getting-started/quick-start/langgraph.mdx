## Goal

Run one credential-free LangGraph workflow and write its lifecycle to a local
Agent Trajectory Observability Format (ATOF) file.

## Prerequisites

Before you start, make sure you have:

- Python 3.11 or newer
- `uv`

<Note icon="circle-info">
Install commands target the Relay version documented here. If that version has
not been released, its pinned packages and downloads are not available yet.
Select a released documentation version to try Relay now.
</Note>

<Steps toc={true}>

## Install

Create a project and install the NeMo Relay version for these docs with the
LangGraph extra.
For an existing `uv` project, run only the `uv add` command from its directory.

{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":600} */}
```bash
mkdir relay-langgraph-quickstart
cd relay-langgraph-quickstart
uv init
uv add "nemo-relay[langgraph]==0.11.0"
```

## Verify

The program checks the event file for matching start and end records from the
`emit_marker` graph node. A successful run prints these markers in order:

{/* quickstart-block {"id":"expected","role":"expected","cwd":"relay-langgraph-quickstart","from":"run","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_GRAPH_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

<Tip>
This deterministic path needs no model credentials. After it works, add a model
and tool node to observe a full agent workflow.
</Tip>
