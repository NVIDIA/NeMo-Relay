Run one local Claude Code session through NeMo Relay and write its agent, model,
and tool lifecycle to a local ATOF event file.

## Prerequisites

- Claude Code 2.1.121 or newer, already authenticated
- NeMo Relay CLI 0.10.0 or newer

Install the latest stable Relay CLI on Linux or macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/NVIDIA/NeMo-Relay/main/install.sh | sh
```

See [Installation](/getting-started/installation#cli) for Python and Windows
installation paths.

## Select Claude Code

Save this file as `config.toml` in the directory where you will run the agent:

```toml
[agents.claude]
command = "claude"
```

## Enable Observability

Save this sibling file as `plugins.toml`:

```toml
version = 1

[policy]
unknown_component = "error"
unknown_field = "error"
unsupported_value = "error"

[[components]]
kind = "observability"
enabled = true

[components.config]
version = 4
enable_full_payloads = false

[components.config.atof]
enabled = true

[[components.config.atof.sinks]]
type = "file"
output_directory = "logs"
filename = "events.jsonl"
mode = "overwrite"
```

ATOF output can contain sensitive prompts, responses, tool arguments, and tool
results. Protect `logs/events.jsonl` even when full payload export is disabled.

## Run Claude Code

From the directory containing both files, run:

```bash
nemo-relay --config "$PWD/config.toml" claude -- "Inspect this repository and use one tool."
```

Relay starts a temporary local gateway and injects Claude Code hooks for this
run. It does not modify your persistent Claude Code plugin configuration.

## Verify the Events

After the session exits, confirm that Relay wrote the local event stream:

```bash
test -s logs/events.jsonl
tail -n 1 logs/events.jsonl | python3 -m json.tool
```
