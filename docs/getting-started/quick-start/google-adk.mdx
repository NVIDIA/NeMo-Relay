## Goal

Run a Google ADK agent and save its activity to a local file. NeMo Relay
records the agent run, model calls, and tool calls. This example checks that
the agent calls a tool and that Relay saves the events.

The file uses Agent Trajectory Observability Format (ATOF), Relay's event format.

## Prerequisites

You need:

- Python 3.11 or newer
- `uv`
- A [Gemini API key](https://aistudio.google.com/apikey)

<Steps toc={true}>

## Install

Create a project. Install NeMo Relay with its Google ADK extra.
If you already have a `uv` project, run only the `uv add` command in that directory.

{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":600} */}
```bash
mkdir relay-google-adk-quickstart
cd relay-google-adk-quickstart
uv init
uv add "nemo-relay[google-adk]==0.11.0"
```

Set your Gemini API key in the current shell.

## Run

The example gives an agent one tool, `emit_marker`. The tool returns a fixed
message so you can check that it ran. The agent then returns a final answer.

## Verify

The program checks the tool result, the final answer, and the saved events.
It also checks that the request, tool call, and model call have matching start
and end events. A successful run prints these messages in order:

{/* quickstart-block {"id":"expected","role":"expected","cwd":"relay-google-adk-quickstart","from":"run","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

<Note icon="circle-info">
The model can use different words around `RELAY_QUICKSTART_RESPONSE_OK`.
The check only requires that message to appear in the final answer.
</Note>

### Inspect the Recorded Activity

Print the details of one completed model call from the event file.

{/* quickstart-block {"id":"inspect","role":"run","cwd":"relay-google-adk-quickstart","shells":["bash","powershell"],"session":"main","timeout_seconds":180} */}
```bash
uv run python -c "
import json
from pathlib import Path
events = [json.loads(line) for line in Path('logs/events.jsonl').read_text().splitlines()]
call = next(event for event in events if event.get('scope_category') == 'end' and event.get('category') == 'llm')
fields = ('name', 'category', 'category_profile', 'uuid', 'parent_uuid', 'timestamp', 'metadata')
print(json.dumps({key: call.get(key) for key in fields}, indent=2))
"
```

Use these fields to understand the call:

| Field | Meaning |
| --- | --- |
| `category` | The kind of activity, such as a model call |
| `name` | The name of the activity |
| `uuid` | The ID shared by the start and end events |
| `parent_uuid` | The ID of the activity that contains this call |
| `timestamp` | The time of the event |
| `category_profile` and `metadata` | Details such as the model name or call status, when available |

For example, a model call's `parent_uuid` links it to the agent that made the call.
