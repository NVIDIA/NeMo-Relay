Run one Hermes Agent turn and write its session, model, and tool lifecycle to a
local ATOF event file.

Hermes Agent 0.18.2 or newer includes NeMo Relay natively. Do not install the
former Hermes Relay observability plugin or launch Hermes through the
`nemo-relay` CLI.

## Prerequisites

- Linux, macOS, or Windows Subsystem for Linux 2 (WSL2)
- A configured Hermes model provider
- Permission to install Hermes in your user environment

## Install and Configure Hermes

Install Hermes on Linux, macOS, or WSL2:

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

Complete the setup prompts and confirm that `hermes` can use your model
provider before continuing.

## Enable Observability

Save the following configuration as `plugins.toml` in the directory where you
will start Hermes:

```toml
version = 1

[policy]
unknown_component = "error"
unknown_field = "error"
unsupported_value = "error"

[[components]]
kind = "observability"
enabled = true

[components.config]
version = 4
enable_full_payloads = false

[components.config.atof]
enabled = true

[[components.config.atof.sinks]]
type = "file"
output_directory = "logs"
filename = "events.jsonl"
mode = "overwrite"
```

Select that file in the shell that will start Hermes:

```bash
export HERMES_NEMO_RELAY_PLUGINS_TOML="$PWD/plugins.toml"
```

ATOF output can contain sensitive prompts, responses, tool arguments, and tool
results. Protect `logs/events.jsonl` even when full payload export is disabled.

## Run One Turn

From the same directory, run a one-shot turn with the common validation prompt:

```bash
hermes chat --oneshot -q "Use one available tool to produce RELAY_QUICKSTART_TOOL_OK. Then include RELAY_QUICKSTART_RESPONSE_OK in your final response."
```

Hermes closes the Relay session before this command exits, allowing queued
observability records to finish writing.

## Verify the Events

```bash
test -s logs/events.jsonl
tail -n 1 logs/events.jsonl
printf 'RELAY_QUICKSTART_EVENTS_OK\n'
```

The transcript should contain `RELAY_QUICKSTART_TOOL_OK`, and the final response
should contain `RELAY_QUICKSTART_RESPONSE_OK`. The verification commands should
print one JSON object from the Hermes session, model request, or tool lifecycle,
then `RELAY_QUICKSTART_EVENTS_OK`.
