## Goal

Run one Deep Agents workflow and write its agent, model, and tool lifecycle to
a local Agent Trajectory Observability Format (ATOF) file.

## Prerequisites

Before you start, make sure you have:

- Python 3.11 or newer
- `uv`
- Inference access: an [NVIDIA API key](https://build.nvidia.com/settings/api-keys) for this example, or credentials for your own provider

<Steps toc={true}>

## Install

Create a project and install the NeMo Relay version for these docs with the
Deep Agents and NVIDIA model provider extras.
For an existing `uv` project, run only the `uv add` command from its directory.

{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":600} */}
```bash
mkdir relay-deep-agents-quickstart
cd relay-deep-agents-quickstart
uv init
uv add "nemo-relay[deepagents,langchain-nvidia]==0.11.0"
```

Set your NVIDIA API key for the current shell:

<Tabs>
<Tab title="Unix shell">
{/* quickstart-block {"id":"credentials","role":"input","cwd":"relay-deep-agents-quickstart","shells":["bash"],"session":"main","env":"NVIDIA_API_KEY"} */}
```bash
export NVIDIA_API_KEY="your-api-key"
```
</Tab>

<Tab title="Windows PowerShell">
{/* quickstart-block {"id":"credentials","role":"input","cwd":"relay-deep-agents-quickstart","shells":["powershell"],"session":"main","env":"NVIDIA_API_KEY"} */}
```powershell
$env:NVIDIA_API_KEY = "your-api-key"
```
</Tab>
</Tabs>

<Note icon="circle-info">
Relay does not impose a model choice. This copyable example selects the public
[`nvidia/nemotron-3-nano-omni-30b-a3b-reasoning`](https://build.nvidia.com/nvidia/nemotron-3-nano-omni-30b-a3b-reasoning/playground)
model through the NVIDIA provider. To use another model or provider, replace
the example's `model` argument and configure that provider's credentials.
The NVIDIA provider reads `NVIDIA_API_KEY`. In the LangChain string, the first `nvidia:`
selects the provider; the remaining `nvidia/...` value is the model ID.
</Note>

<Note icon="circle-info">
The provider can warn that this model is "not known to support tools" when its
capability catalog lags the endpoint. This warning is advisory; the run must
still produce the actual tool result and all three success lines below.
</Note>

## Verify

The program checks the tool result, final assistant response, and paired ATOF
agent, tool, and LLM records. A successful run prints these markers in order:

{/* quickstart-block {"id":"expected","role":"expected","cwd":"relay-deep-agents-quickstart","from":"run","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

<Note icon="circle-info">
The model can use different wording around the response marker. These checks
validate a live provider call; they do not make the model deterministic.
</Note>
