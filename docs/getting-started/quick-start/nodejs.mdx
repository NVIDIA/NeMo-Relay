## Goal

Instrument one scope, tool call, and large language model (LLM) call with NeMo Relay, then verify the
result in a local Agent Trajectory Observability Format (ATOF) file.

<Note icon="circle-info">
This example uses local tool and model callbacks. It does not require an
inference key or a live model.
</Note>

## Prerequisites

Before you start, make sure you have:

- Node.js 24 or newer
- npm

<Steps toc={true}>

## Install

Create a project and install the NeMo Relay version for these docs.
For an existing Node.js project, run only the `npm install` command from its directory.

{/* quickstart-block {"id":"install","role":"run","cwd":".","shells":["bash","powershell"],"session":"main","timeout_seconds":600} */}
```bash
mkdir relay-node-quickstart
cd relay-node-quickstart
npm init -y
npm install --save-exact nemo-relay-node@0.11.0
```

Save the following configuration as `plugins.toml` in your project directory:

</Warning>

## Run

Save this file as `quickstart.js` beside `plugins.toml`:

{/* quickstart-block {"id":"program","role":"file","cwd":"relay-node-quickstart","path":"quickstart.js"} */}
<Code src="_code/nodejs/quickstart.js" language="js" title="quickstart.js" />

Run it from the project directory so the relative output path resolves there:

{/* quickstart-block {"id":"run","role":"run","cwd":"relay-node-quickstart","shells":["bash","powershell"],"session":"main","timeout_seconds":180} */}
```bash
node quickstart.js
```

## Verify

The program checks the event file for paired agent, tool, and LLM lifecycle
records. A successful run prints these markers in order:

{/* quickstart-block {"id":"expected","role":"expected","cwd":"relay-node-quickstart","from":"run","match":"exact-lines"} */}
```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

<Note icon="circle-info">
The file stores ATOF events as newline-delimited JSON (JSONL).
</Note>

</Steps>
