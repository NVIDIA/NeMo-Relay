Instrument one scope, tool call, and LLM call with NeMo Relay, then verify the
result in a local ATOF event file.

## Prerequisites

- Rust 1.86 or newer
- Cargo

## Install NeMo Relay

Create a project and add the verified published crate:

```bash
cargo new relay-rust-quickstart
cd relay-rust-quickstart
cargo add "nemo-relay@=0.9.1"
cargo add serde_json
cargo add tokio --features macros,rt-multi-thread
```

## Enable Observability

Save the following configuration as `plugins.toml` in your project directory:

```toml
version = 1

[policy]
unknown_component = "error"
unknown_field = "error"
unsupported_value = "error"

[[components]]
kind = "observability"
enabled = true

[components.config]
version = 4
enable_full_payloads = false

[components.config.atof]
enabled = true

[[components.config.atof.sinks]]
type = "file"
output_directory = "logs"
filename = "events.jsonl"
mode = "overwrite"
```

ATOF output can contain sensitive prompts, responses, tool arguments, and tool
results. Protect `logs/events.jsonl` even when full payload export is disabled.

## Run an Instrumented Workflow

Save this file as `src/main.rs` beside the project's `Cargo.toml`:

```rust
use nemo_relay::api::llm::{llm_call_execute, LlmCallExecuteParams, LlmRequest};
use nemo_relay::api::scope::{
    self, EmitMarkEventParams, PopScopeParams, PushScopeParams, ScopeAttributes, ScopeType,
};
use nemo_relay::api::subscriber::flush_subscribers;
use nemo_relay::api::tool::{tool_call_execute, ToolCallExecuteParams, ToolExecutionResult};
use nemo_relay::plugin::dynamic::initialize;
use nemo_relay::plugin::PluginConfig;
use serde_json::json;
use std::fs;
use std::io;
use std::path::PathBuf;
use std::sync::Arc;

async fn run_workflow() -> Result<(), Box<dyn std::error::Error>> {
    let handle = scope::push_scope(
        PushScopeParams::builder()
            .name("demo-agent")
            .scope_type(ScopeType::Agent)
            .attributes(ScopeAttributes::empty())
            .data(json!({"binding": "rust"}))
            .build(),
    )?;

    let workflow_result: Result<(), Box<dyn std::error::Error>> = async {
        scope::event(
            EmitMarkEventParams::builder()
                .name("initialized")
                .parent(&handle)
                .data(json!({"ok": true}))
                .build(),
        )?;

        let tool_result = tool_call_execute(
            ToolCallExecuteParams::builder()
                .name("emit_marker")
                .args(json!({"marker": "RELAY_QUICKSTART_TOOL_OK"}))
                .func(Arc::new(|args| Box::pin(async move {
                    Ok(ToolExecutionResult::new(json!({"marker": args["marker"]})))
                })))
                .parent(handle.clone())
                .build(),
        )
        .await?;

        let llm_result = llm_call_execute(
            LlmCallExecuteParams::builder()
                .name("demo-provider")
                .request(LlmRequest {
                    headers: Default::default(),
                    content: json!({
                        "messages": [{
                            "role": "user",
                            "content": "RELAY_QUICKSTART_RESPONSE_OK"
                        }]
                    }),
                })
                .func(Arc::new(|_| Box::pin(async move {
                    Ok(json!({"content": "RELAY_QUICKSTART_RESPONSE_OK"}))
                })))
                .parent(handle.clone())
                .model_name("demo-model")
                .build(),
        )
        .await?;

        println!(
            "{}",
            tool_result.result["marker"]
                .as_str()
                .ok_or_else(|| io::Error::other("tool marker is missing"))?
        );
        println!(
            "{}",
            llm_result["content"]
                .as_str()
                .ok_or_else(|| io::Error::other("response marker is missing"))?
        );
        Ok(())
    }
    .await;

    let pop_result = scope::pop_scope(
        PopScopeParams::builder().handle_uuid(&handle.uuid).build(),
    );
    workflow_result?;
    pop_result?;
    Ok(())
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut activation = initialize(
        PluginConfig::default(),
        Some(PathBuf::from("plugins.toml")),
    )
    .await?;

    let work_result = run_workflow().await;
    let flush_result = flush_subscribers();
    let close_result = activation.close();
    work_result?;
    flush_result?;
    close_result?;

    let event_text = fs::read_to_string("logs/events.jsonl")?;
    let last_event = event_text
        .lines()
        .last()
        .ok_or_else(|| io::Error::other("Relay event file is empty"))?;
    serde_json::from_str::<serde_json::Value>(last_event)?;
    println!("RELAY_QUICKSTART_EVENTS_OK");
    Ok(())
}
```

Run it from the project directory so the relative output path resolves there:

```bash
cargo run
```

## Verify the Events

The program validates the event file and prints, in order:

```text
RELAY_QUICKSTART_TOOL_OK
RELAY_QUICKSTART_RESPONSE_OK
RELAY_QUICKSTART_EVENTS_OK
```

The event file contains scope, tool, and LLM records in ATOF JSONL format.
