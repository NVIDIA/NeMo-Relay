CLI and language package commands install the latest stable Relay release.
Agent harnesses manage their compatible Relay dependencies. Quick starts pin
their example versions and include configuration, a first task, and verification.

For administrator-managed services, use [Deploy Overview](/getting-started/deploy).
For a first working example, use [Quick Starts](/getting-started/quick-start).
For source builds or repository development, use
[Development Setup](/contribute/development-setup).
