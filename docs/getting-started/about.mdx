## Using an AI Coding Assistant

[NVIDIA agent skills](https://docs.nvidia.com/skills) give your assistant
Relay-specific installation, instrumentation, plugin, migration, and debugging
workflows.

<Accordion title="Install all Relay skills" icon="fa-solid fa-wand-magic-sparkles">

With Node.js and npm available, run this in your project:

```bash
npx skills@latest add nvidia/skills \
  --skill nemo-relay-install \
    nemo-relay-get-started \
    nemo-relay-instrument-calls \
    nemo-relay-instrument-context-isolation \
    nemo-relay-instrument-typed-wrappers \
    nemo-relay-plugin-adaptive-tuning \
    nemo-relay-plugin-build \
    nemo-relay-plugin-observability \
    nemo-relay-migrate-from-flow \
    nemo-relay-debug-runtime-integration
```

The installer detects compatible agents and lets you choose where to install.
For agent selection and project or global scope, use the
[skills installation guide](https://docs.nvidia.com/skills/advanced-install).

Then ask your assistant:

> Help me choose the right Relay setup for this project and verify a first run.

Browse the [NVIDIA/skills catalog](https://github.com/NVIDIA/skills#skill-catalog)
for skill descriptions and updates.

</Accordion>
