NeMo Relay observes and controls agent work at the boundary where it runs.
Choose the path that matches the agent runtime, framework, or application you
already use. The [Quick Start](/getting-started/quick-start) page lists working
examples that install a verified release, enable built-in observability, run
one workflow, and check the local event output.

## Choose Where Relay Attaches

Use the boundary that owns the model request or tool execution:

- **Agent runtime:** Observe Hermes, Claude Code, Codex, pi, or OpenClaw without
  changing application code.
- **Framework:** Use the maintained LangChain, LangGraph, or Deep Agents
  integration when the framework owns callbacks and tool execution.
- **Application:** Instrument Python, Node.js, or Rust code when your
  application owns the tool or model call.
- **Routing plugin:** Use Switchyard when Relay should route model requests.

Each path has its own requirements. You do not need a Rust compiler, a source
checkout, or repository development tools to install a published CLI binary.

## Using an AI Coding Assistant

<Card
  title="NVIDIA Agent Skills"

Install [NVIDIA agent skills](https://docs.nvidia.com/skills) to give
compatible coding agents product-specific Relay workflows and references. After
the NeMo Relay skills are published in `nvidia/skills`, install the full Relay
skill set without cloning the catalog:

```bash
npx skills add nvidia/skills \
  --skill nemo-relay-install \
  --skill nemo-relay-get-started \
  --skill nemo-relay-instrument-calls \
  --skill nemo-relay-instrument-context-isolation \
  --skill nemo-relay-instrument-typed-wrappers \
  --skill nemo-relay-plugin-observability \
  --skill nemo-relay-plugin-adaptive-tuning \
  --skill nemo-relay-plugin-build \
  --skill nemo-relay-migrate-from-flow \
  --skill nemo-relay-debug-runtime-integration \
  --agent codex
```

Use `--agent claude-code`, `--agent cursor`, or another supported agent target
when that is where you want the skill installed. To inspect the current NVIDIA
skill catalog first, run:

```bash
npx skills add nvidia/skills --list
```

Agent skills help your coding assistant apply Relay documentation and workflows.
They do not replace installing NeMo Relay packages, configuring runtime
plugins, or validating emitted events.
