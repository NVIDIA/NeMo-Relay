Use this page to plan an upgrade to NeMo Relay 0.10. It will collect required
upgrade actions as they are identified during the 0.10 development cycle.

## Upgrade to NeMo Relay 0.10

### Refresh Codex Provider Routing

After upgrading the CLI, refresh personal Relay-managed Codex installations:

```bash
nemo-relay integrations refresh
```

To refresh only Codex, use `nemo-relay install codex --force`. Refreshing Codex
switches persistent routing to the built-in OpenAI provider, preserving session
identity and routing image generation through Relay.
