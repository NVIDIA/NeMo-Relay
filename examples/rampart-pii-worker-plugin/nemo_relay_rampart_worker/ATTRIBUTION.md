# Rampart Model Attribution

This plugin loads `nationaldesignstudio/rampart` and adapts its deterministic
pre-mask and model post-processing behavior. Rampart is released by National
Design Studio under the Creative Commons Attribution 4.0 International
license. The plugin pins model revision
`b1993e4e68b082835b80ffc65acc03325ea2e501`.

Model weights are downloaded into the user's Hugging Face cache and are not
redistributed with NeMo Relay or the worker package.

- Model: https://huggingface.co/nationaldesignstudio/rampart
- Project: https://github.com/nationaldesignstudio/rampart
- License: https://creativecommons.org/licenses/by/4.0/
